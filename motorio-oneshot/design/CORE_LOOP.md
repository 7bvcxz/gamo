# CORE_LOOP — 무엇이 무엇을 돌리는가

상태: `[초안]` · 2026-08-13

Motorio의 루프는 다섯 개의 시스템이 서로를 먹여 살리는 구조다. **하나를 바꾸면 나머지
넷이 어떻게 되는지** 먼저 확인한다.

---

## 다섯 시스템과 그 관계

```
        탐험 ──────────────► 자원 · 고양이 · 파편
         ▲                          │
         │                          ▼
      온기 반경 ◄───────────────── 열
         ▲                          ▲
         │                          │
       고양이 ─────► 자동화 ─────► 생산
                       ▲            │
                       └── 물류 ◄───┘
```

읽는 법:

- **탐험은 열이 허락하는 만큼만 가능하다.** 더 멀리 가려면 더 따뜻해야 한다.
- **열은 자원에서 나온다.** 자원은 탐험해서 찾는다.
- **고양이는 따뜻한 곳에서만 안정적으로 일한다.** 그래서 자동화는 열을 요구한다.
- **자동화가 생산을 늘린다.** 생산이 열을 늘린다. 열이 탐험 범위를 늘린다.
- **물류는 이 고리를 감아 조인다** — 손으로 나르던 것을 벨트가 대신하면 고리가 빨라진다.

**이 그림이 깨지는 순간이 설계 실패다.** 예를 들어 열 없이도 고양이가 아무 데서나 일하면
온기 확장이 할 일이 없어지고, 온기 확장이 할 일을 잃으면 이 게임의 세 번째 기둥(얼어붙은
세계가 살아나는 과정)이 통째로 사라진다.

---

## Early Loop — 손으로 도는 고리

```
탐험 ──► 자원 발견 ──► 채굴 ──► 귀환 ──► 생존
  ▲                                       │
  └───────────── 온기 회복 ◄───────────────┘
```

**병목은 플레이어의 몸이다.** 체온이 시계이고, 한 번에 나갔다 올 수 있는 거리가 곧
게임의 크기다. 이 단계는 짧아야 한다 — 재미가 "참는 것"이기 때문이다.

*현재 구현: 온기 반경 밖 체온 -13/초, 0이 되면 쓰러져 기지로 귀환. 이 고리는 이미 돈다.*

---

## Companion Loop — 남이 대신 도는 고리

```
탐험 ──► 얼어붙은 고양이 발견 ──► 기지로 운반 ──► 해동
                                              │
                    ┌─────────────────────────┘
                    ▼
            광맥 위에 올려놓기 ──► 고양이가 채굴 ──► 고양이가 운반 ──► 기지
```

여기서 처음으로 **플레이어가 손을 떼도 자원이 는다.** 아직 매우 느리다. 느린 것이
맞다 — 다음 단계의 벨트가 빨라 보여야 하기 때문이다.

고양이는 춥고 배고프다. 그래서:

- 고양이를 멀리 두려면 그곳을 따뜻하게 해야 한다 → **열 확장의 동기**
- 고양이가 밥을 먹어야 한다 → **식량 생산의 동기**

*현재 구현: 고양이는 있고 배고픔·귀가·작업이 다 돈다. 다만 **얼어붙은 고양이를 구하는
경로가 없다** — 상자 3개를 모아 숙소에서 입양한다. `CURRENT_STATE.md` 참고.*

---

## Automation Loop — 고리가 스스로 도는 순간

```
        ┌──────────── 벨트 ◄────────────┐
        ▼                               │
   기지에 적재 ◄── 벨트 ◄── 채굴기 ◄── 고양이(채굴만)
        │
        ▼
   열 · 재료 ──► 더 많은 설비
```

**변하는 것은 속도가 아니라 고양이의 역할이다.** 고양이가 "캐고 나르는 존재"에서
"캐는 존재"가 된다. 나르기가 사라지는 것이 이 단계의 전부다.

이 순간을 강하게 만드는 방법은 **직전을 충분히 답답하게 만드는 것**이다. 벨트 이전에
고양이가 왕복하는 모습을 플레이어가 충분히 보아야 한다.

*현재 구현: 벨트·분배기·채굴기·교환기·발전기가 있고 오토타일링으로 하나의 길로 읽힌다.*

---

## Exploration Loop — 눈안개 너머

```
장비 준비(횃불·연료) ──► 눈안개 진입 ──► 제한 시간 안에 탐색
                                            │
        ┌───────────────────────────────────┘
        ▼
  Crystal · 우주선 파편 · 얼어붙은 고양이 · 마을 · 냥파편의 흔적
        │
        ▼
  새 기술 ──► 더 긴 탐험 ──► 더 먼 곳
```

탐험의 화폐는 **시간**이다. 횃불이 시야와 체류 시간을 산다. 고에너지 횃불이 없다고
진입이 막히지는 않는다 — 다만 짧고 어둡고 길을 잃는다.

*현재 구현: 횃불이 없다. 탐험 가능 범위는 온기 반경이 전부다.*

---

## Mid Loop — 영토가 되는 고리

```
탐험 ──► 자원지대 / 마을 발견
   │
   ▼
Heat Network 연장 ──► 전초기지 건설 ──► 물류 연결 ──► 생산 증가
   │                                                    │
   └────────────────── 더 많은 열 ◄─────────────────────┘
```

기지가 하나에서 **여러 곳**이 된다. 이때부터 플레이어가 푸는 문제는 "더 많이 캐기"가
아니라 **"어디에 무엇을 둘 것인가"**다.

---

## Late Loop — 규칙을 깨는 고리

```
고대 지역 탐사 ──► 냥파편 기술 발견 ──► 연구
                                        │
                                        ▼
                        기존 자동화의 한계를 깨는 설비
                        (Teleporter · Replicator · Space Beam)
                                        │
                                        ▼
                              대규모 산업 확장
```

여기서 앞의 모든 고리가 **한 번씩 무효화된다.** 벨트를 깔던 사람이 Teleporter를 놓고,
발전기를 세우던 사람이 Zero Point Heater를 놓는다. 이것이 보상으로 느껴지려면 앞 고리를
충분히 오래 돌았어야 한다.

---

## End Loop — 두 갈래

```
산업화 ──► 고대 기술 복원 ──► 우주선 복원 ──► Normal Ending (떠난다)
                │
                └──► True Route 발견 ──► 복수의 자동화 ──► Penguin Planet
```

## 루프 설계 체크리스트

새 시스템을 넣기 전에 답한다.

1. 이 시스템은 위 다섯 중 **무엇을 먹고 무엇을 먹이는가**?
2. 이것이 들어오면 **어떤 행동이 사라지는가**? (사라지는 게 없으면 숫자 업그레이드다)
3. 이것 없이도 **들어갈 수는 있는가**? (없으면 Hard Gate다)
4. 플레이어가 이걸 얻는 순간 **무슨 문장을 말하는가**?
