# Gunslinger — 서부 총잡이 1대1 한방 대결 POC

## 핵심 검증 질문

**"대기 → 신호 → 순간 반응"의 긴장감이 반복 플레이하고 싶을 만큼 재미있는가?**

이 POC는 그 한 가지를 확인하려고 만든다. 총을 뽑기 전의 정적, 언제 올지 모르는
신호, 그리고 손가락이 머리보다 먼저 움직이는 순간 — 이것만으로 "한 판 더"가
나오는지. 나오지 않는다면 무엇을 더 붙여도 소용없고, 나온다면 나머지는 전부
그 위에 얹는 살이다.

아래 조건은 그 질문에 답하기 위한 최소한이다. 조건을 다 채우는 것이 목적이 아니라,
채운 뒤 실제로 재미있는지 판단하는 것이 목적이다.

## 완료 조건

- [x] 타이틀 → 대결 → 결과 → 재대결 흐름이 끊김 없이 순환한다
- [x] 대결 시작 후 **2~6초 사이 무작위 시점**에 "DRAW!" 신호가 나타난다
- [x] 신호 후 먼저 입력한 쪽이 승리하고, 그 **반응시간이 ms 단위로 표시**된다
- [x] 신호 전에 입력하면 **반칙패**로 즉시 패배 처리된다
- [x] AI 난이도 3단계 — 단계별로 **반응속도가 다르다**
- [x] 승리 연출 1종, 패배 연출 1종
- [x] **3판 2선승** 매치로 진행되고 매치 승자가 결과 화면에 표시된다
- [x] `godot --headless --path gunslinger --quit-after 5` 실행 시 에러 0건
- [x] HTML5 export 성공, **모바일 터치 입력 지원**

## 하지 말 것

- **온라인 멀티플레이.** 네트워크 코드, 매치메이킹, 서버, 순위표 전부 포함이다.
  1대1은 사람과 AI의 1대1을 말한다.

## 참고

- 아트는 도형과 색만 쓴다. 총잡이는 사각형과 원이어도 된다. 이 POC가 답하려는
  질문에 그림 실력은 변수가 아니다.
- 조건에 없는 아이디어가 떠오르면 구현하지 말고 `PROGRESS.md`의 `## 제안`에
  한 줄로 남긴다.
- 반응시간을 다룰 때 프레임 단위와 실제 경과 시간은 다르다. 신호 시각과 입력 시각은
  프레임 수가 아니라 실제 시계로 재야 ms 표시가 의미를 갖는다.
