Popcorn & Glory

팝콘 가게. 누르고 있다가 금색에서 떼면 팝콘이 터집니다. 설치 없이 브라우저에서 합니다.

팝콘 가게 플레이 선택 화면 (세 실험과 가게) 3분 점수표

하는 법

기계를 누르고 있으면 고리가 찹니다. 금색에서 떼면 완벽한 팝, 너무 오래 누르면 탑니다. 돈이 모이면 아래 카드로 가게를 키웁니다. 가게가 자라면 흔들기(누른 채 좌우로), 자동화(모터, 조수 냄비), 양념 셋이 하나씩 열립니다. 휴대폰은 세로로 두는 것이 가장 좋습니다.

개인정보

  • 계정, 결제, 광고, 분석 도구가 없습니다. 게임 파일을 받는 것 말고는 어디로도 요청을 보내지 않습니다.
  • 가게의 진행은 이 브라우저의 저장소(localStorage, 키 popcorn-glory.stand.v1)에만 남습니다. 점수표는 popcorn-glory.scorecard.v1입니다. 다른 기기로 옮겨지지 않고, 브라우저의 사이트 데이터를 지우면 함께 지워집니다.
  • 게임 안에서 처음부터 다시 하려면 오른쪽 위의 다시 시작 버튼을 두 번 누릅니다(첫 번째는 버튼이 빨개지기만 합니다). 저장도 함께 지워집니다.
  • 개발용 기록 내려받기(?dev=1)는 이 기기에 파일을 만들 뿐 보내지 않습니다.

문의

문제나 의견은 GitHub 저장소의 이슈로 남겨 주세요: github.com/7bvcxz/gamo/issues. 이 게임은 아직 출시 후보입니다.

그림, 소리, 라이선스

  • 그림은 이 저장소에서 손으로 쓴 도형과 SVG이고, 소리는 스크립트로 합성했습니다. 생성 이미지, 녹음, 외부 그림이나 소리는 없습니다 (목록: design/ART_AUDIO.md).
  • 엔진은 Godot Engine 4.7(MIT 라이선스)입니다. 엔진이 쓰는 제3자 구성 요소의 고지는 그 페이지에 있습니다.
