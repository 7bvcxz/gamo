Bubble Wrap Empire

뽁뽁이를 가볍게 한 번 누르면 터짐이 파도처럼 번집니다. 증분 게임 POC 두 개 중 두 번째(연쇄 반응).

확인하려는 질문

손은 가끔만 쓰는데도 “큰 파도가 이어진다”는 느낌이 재미있는가?

아직 답이 없습니다. 사람이 해 보기 전에는 재미도 피로도도 알 수 없습니다. 아래 수치는 자동 브라우저 조작이 잰 기술 증거이고, 사람의 즐거움이나 손의 피로가 아닙니다.

하는 법

  • 오른쪽 아래 칸은 시트의 작은 지도입니다. 엄지를 올린 곳에 대응하는 시트 위 뽁뽁이에 분홍 고리가 뜨고, 놓으면 거기서 터집니다. 정밀한 조준은 필요 없고, 시트를 직접 눌러도 됩니다.
  • 한 번 만지면 한 번만 터뜨립니다(아주 짧은 쓸기도 같은 한 번). 문지르거나 충전할 필요가 없습니다.
  • 놓은 뒤 이웃이 차례로 부풀었다 터지며 번집니다. 통화는 POP 하나, 터진 뽁뽁이는 부드럽게 다시 부풉니다.
  • 왼쪽 아래 다섯 버튼: 반경·연쇄(몇 칸 번지나)·값·리필 속도·메가(저절로 차오르는 큰 파도, 준비되면 엄지 칸 테두리가 금색).
  • 가득 찬 뽁뽁이만 터지므로 연타는 시트를 비울 뿐 더 벌지 못합니다. 기다려도 잃는 것이 없습니다.
  • 키보드: 스페이스 = 가운데에서 터뜨리기, 1–5 = 업그레이드, M = 소리, H = 숫자 숨김.
  • 위쪽 버튼: 초기화(두 번 눌러 확인), ⓘ 입력 지표(복사 가능), ⇄ 좌우 반전, 소리 끄기. 엄지 칸 아래 막대는 연속 터치 감쇠(너무 빠른 터치는 값이 줄어듦)를 보여 줍니다.

10분 비교 (자동, 저입력 vs 연타)

저입력(4초마다 한 번)과 연타(초당 약 6~10회)를 같은 빌드에서 10분씩 돌렸습니다. 연타의 POP은 저입력의 1분 10배 · 3분 2.0배 · 10분 1.4배였습니다 — 처음 1분은 탭 속도가 복리로 크게 갈리고, 그 뒤에는 격차가 줄며 연타의 파도는 작습니다(3분 시점 14개 vs 70개). 저입력은 78초에 시트 전체가 한 파도가 되어 이후 파도 크기는 더 자라지 않습니다. 머신 부하가 높은 상태(평균 38)의 세션이라 fps는 참고용입니다.

직접 해 보기 (사람 평가용)

  1. 새 게임으로 3분, 설명 없이 해 본다.
  2. 선택: 실제 폰에서 10분, 편한 자세로(엄지 / 두 손 / 책상 위 검지). 좌우가 불편하면 ⇄.
  3. 불편하면 즉시 멈춘다. 끝나면 재미 0–10, 피로 0–10, 스스로 더 만졌는지, 다시 하고 싶은지를 적는다.
  4. ⓘ → COPY로 지표를 붙여 두면 객관 수치가 남는다.
