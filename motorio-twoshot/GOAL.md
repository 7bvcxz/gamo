# GOAL: Motorio Vertical Slice (첫 30분)

## 핵심 검증 질문

"첫 고양이가 깨어나 일하는 순간"과 "첫 컨베이어 자동화 순간"이
계속 하고 싶게 만드는가?

## 완료 조건

- [ ] 불시착 → 긴급기지 → Heat Zone 생성 흐름
- [ ] 체온 게이지, 외부에서 시간당 감소
- [ ] Heatstone 채굴 → 기지 연료 공급
- [ ] 첫 고양이 구출 연출(얼음 녹음 → 눈뜸 → "먀?")
- [ ] 고양이를 광석 위에 놓으면 채굴+운반 시작
- [ ] 구리 발견 → Conveyor 제작 → 완전 자동 생산라인 1개
- [ ] 낮/밤 사이클, 밤 체온 감소 가속 (Hard Lock 없음)
- [ ] 처음부터 컨베이어까지 30분 이내 플레이 가능
- [ ] headless 에러 0, HTML5 export 성공

## 참고

- 설계 문서가 단일 원본이다. `VISION.md`와 `docs/game-design/`의 네 문서를 먼저 읽고,
  특히 `VERTICAL_SLICE.md`가 이 GOAL의 각 조건을 분 단위 흐름으로 풀어 놓았다.
  조건과 문서가 어긋나면 문서를 먼저 고친다.
- 이 폴더는 아직 Godot 프로젝트가 아니다. 첫 조건에 착수할 때 `project.godot`와
  Web export preset을 함께 만든다(`AGENTS.md`의 새 게임 규칙).
- `../motorio`에 이 조건의 상당수가 이미 다른 형태로 구현되어 있다.
  무엇을 가져오고 무엇을 다시 만들지는 `docs/game-design/CURRENT_STATE.md`에 정리했다.
  **베끼기 전에 그 문서의 "비전과 충돌하는 것"을 먼저 읽는다** — 특히 고양이 획득 경로는
  그대로 가져오면 안 된다.
- "30분 이내"는 감이 아니라 측정값이어야 한다. `motorio/tools/trace_scenario.gd`가
  하는 것처럼 헤드리스로 시나리오를 돌려 각 마일스톤 도달 시각을 찍는 도구를 함께 만든다.
- 조건에 없는 아이디어가 떠오르면 구현하지 말고 `PROGRESS.md`의 `## 제안`에 한 줄로 남긴다.
