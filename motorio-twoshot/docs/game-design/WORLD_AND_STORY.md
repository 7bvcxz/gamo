# WORLD_AND_STORY — 얼음고양이행성

`../../VISION.md`가 단일 원본이다. 이 문서는 세계와 이야기를 다룬다.

**톤 규칙이 먼저다.** 지구 멸망의 원인은 펭귄이고, 왜인지는 아직 모른다.
진지한 SF가 아니라 귀엽고 이상하고 약간 황당한 세계다. 그러나 가벼운 것과 값싼 것은
다르다 — 얼어붙은 마을에 불이 들어오는 순간은 진심이어야 한다.

---

## 1. Grim

주인공. 지구에서 살던 사람이고, 특별한 능력은 없다.

전투 영웅이 아니라 **엔지니어**다. 이 게임에서 Grim이 가진 유일한 힘은 만드는 것이고,
그래서 최종 복수도 총이 아니라 공장으로 한다(금지 사항 5.4).

`[확정]` Grim의 스프라이트와 애니메이션 자산은 `../motorio-oneshot/assets/characters/`에
이미 있다 — 128px 셀 8프레임, 발 기준점 (64, 104), 서쪽은 동쪽 반전.
대기·걷기·달리기·채굴의 남/동/북 시트가 갖춰져 있다.

`[질문]` Grim의 과거를 얼마나 드러낼지. 지금은 "지구에 살았고 탈출했다" 이상은 없다.
비어 있는 편이 플레이어가 들어가기 쉽다는 판단도 가능하다.

## 2. 지구 폭발 — 오프닝

```
1. Grim은 지구에서 살고 있었다.
2. 정체불명의 펭귄 집단이 지구를 공격한다.
3. 폭발 약 1시간 전, Grim이 우주선으로 탈출한다.
4. 탈출 도중 지구가 폭발한다.
5. 충격으로 항로가 망가지고 Grim은 기절한다.
6. 깨어 보니 정체불명의 얼음 행성으로 추락 중이다.
7. 우주에서 보면 그 행성은 얼음 고양이 귀 두 개를 가진 모양이다.
8. 비상 탈출을 시도한다.
9. 우주선이 얼음구름과 충돌해 부서진다.
10. 파편들이 행성 곳곳으로 흩어진다.
11. Grim이 불시착한다.
12. 기절한다.
13. 얼어 죽기 직전 정신을 차린다.
14. 게임 시작.
```

**설계상 중요한 것은 9~10번이다.** 우주선이 여기서 부서져 파편이 흩어졌다는 사실이
게임 전체의 장기 목표(Spaceship Fragment 수집)를 만든다. 오프닝이 곧 엔드게임의
설치 작업이다.

**7번도 그냥 농담이 아니다.** 행성이 고양이 모양이라는 것은 플레이어가 나중에
"이 행성 자체가 고양이 문명의 산물인가?"를 의심하게 만드는 씨앗이다. `[초안]`

`[질문]` 오프닝을 어떻게 보여줄지 — 플레이 가능한 추락 장면인지, 정지 화면 몇 장인지,
아니면 깨어나는 것부터 시작하고 회상으로 흘릴지. Vertical Slice의 첫 30초를 좌우한다.

## 3. Penguin

지구를 파괴한 존재. 게임 대부분의 시간 동안 **화면에 나오지 않는다.**

| 시기 | 플레이어가 아는 것 |
|---|---|
| 오프닝 | 펭귄이 지구를 부쉈다 |
| Lv0~2 | 잊는다. 눈앞의 추위가 더 급하다 |
| Lv3~ | Lore 조각으로 다시 떠오른다 |
| End | 찾아갈 수 있다는 것을 깨닫는다 |

**왜 지구를 공격했는지는 아직 정하지 않았다** `[질문]`. 끝까지 밝히지 않는 것도 선택지다 —
"펭귄이 그랬다. 이유는 모른다"가 이 게임의 톤에 더 맞을 수 있다.

펭귄은 잔혹하게 다루지 않는다. Space Beam을 맞은 펭귄은 죽는 대신:

```
🐧 → Space Beam → 😵‍💫 → 안전모 착용 → 고양이 공장에서 일하기 시작
```

## 4. Ice Cat Planet

얼어붙은 행성. 한때 **고양이 문명**이 있었고 지금은 전부 얼어 있다.

이 사실이 세계의 모든 것을 설명한다:
- 얼어붙은 고양이가 왜 여기저기 있는가 → 문명이 통째로 얼었으므로
- 마을이 왜 있는가 → 사람이 살던 곳이므로
- 냥파편이 왜 있는가 → 그들의 기술이므로
- 왜 그들이 지구보다 앞섰는가 → 아직 모른다 `[질문]`

**무엇이 이 행성을 얼렸는가는 정하지 않았다** `[질문]`. 자연 현상인지, 사고인지,
누군가 그랬는지. 펭귄과 연결하면 이야기가 깔끔해지지만 지나치게 정돈되어 톤을 해칠 수도
있다. 이건 사용자 결정 사항이다.

### 지형의 층위 `[초안]`

```
중심부         시작 지점. 온기가 닿는 곳
근거리         Heatstone, 첫 고양이, 첫 광맥
중거리         구리, 눈안개의 시작
원거리         Crystal, 우주선 파편, 마을
고대 지역      냥파편, 문명의 흔적
```

거리가 곧 난이도이고, 난이도는 벽이 아니라 **체온 소모 속도**로 표현된다(Pillar 2).

## 5. Cat Village

탐험의 가장 강력한 감정적 보상. 반복되는 생산 루프 사이에 놓인 **쉼표**다.

### 처음 발견했을 때

```
모든 것이 얼어 있다
집에 불이 꺼져 있다
고양이들이 얼어 있다
음악이 없다 — 바람 소리만
```

여기서 아무것도 주지 않는다. 자원도, 해금도. **볼 것만 준다.**

### Heat Network를 연결한 뒤

```
Base
 🔥
 │
 │
 🔥──── Cat Village
```

마을이 녹기 시작한다.

```
고양이가 움직인다 → 집에 불이 켜진다 → 마을 음악이 시작된다
→ 고양이 모집 가능 → 새 기능 → 특수 기술 → Story/Lore
```

**설계 지침** `[확정]`: 마을 복구 보상을 `+100 Resource`로 끝내지 않는다.
플레이어의 행동으로 **세상이 살아났다는 것**을 보여준다. 음악이 켜지는 것이
자원 100개보다 크다.

### 마을마다 다른 역할 `[초안]`

- Mining Village — 채굴 특화 고양이, 채굴 기술
- Engineer Village — 설비 기술
- Research Village — 연구 가속
- Ancient Village — 냥파편 Lore의 핵심

`[질문]` 마을이 몇 개인지, 각각을 언제 만나는지.

## 6. Spaceship Fragment

오프닝에서 부서진 우주선의 파편. 행성 곳곳에 흩어져 있다.

**역할은 자원이 아니라 이정표다.** 하나 발견할 때마다 플레이어는 생각한다 —
*언젠가는 이곳을 떠날 수 있겠구나.*

| | |
|---|---|
| 얻는 법 | 탐험 중 발견. 파밍이 아니라 조우 |
| 쓰는 법 | 모아서 우주선 복원 (Lv9) |
| 감정 | 장기 목표의 상기 |

`[질문]` 총 몇 개인지, 발견 위치가 고정인지. 고정이면 공략이 생기고, 무작위면
"마지막 하나를 못 찾아 끝을 못 보는" 상태가 생긴다. 고정 쪽이 안전해 보인다.

## 7. Nya Fragment (냥파편)

이 세계관에서 가장 중요한 특수 자원. **희귀 광물이 아니라 규칙을 깨는 물질**이다.

### 발견의 순서 `[확정]`

```
Unknown Fragment
      ???
       ↓
   분석 시작
       ↓
이상한 특성들이 하나씩 드러난다
```

드러나는 특성:
- 엄청난 에너지 밀도
- 공간 왜곡
- 물질 복제
- 순간 이동
- 무한에 가까운 에너지
- 지구 과학으로 설명되지 않는 성질

게임이 진행될수록 **고양이 문명이 과거에 이 기술을 썼다**는 사실이 드러난다.

### 냥파편 기술 `[초안]`

- Teleporter
- Matter Replicator
- Cat Replicator
- Space Beam
- Zero Point Heater
- Pocket Storage
- Gravity Logistics

후반부는 의도적으로 **Power Fantasy**를 제공한다. 여기서는 밸런스를 조심스럽게 잡는
것보다 플레이어를 놀라게 하는 것이 중요하다.

### 등장 규칙 `[확정]`

초중반에 강력한 냥파편 기술을 주지 않는다. 플레이어가 기존 시스템을 충분히 쓴 뒤에만
그 규칙을 깰 수 있다. 대응 관계는 `CORE_LOOP.md` §4의 표에 있다.

> 플레이어가 게임의 규칙을 충분히 배운 뒤, 후반의 보상으로 그 규칙을 깨뜨릴 수 있게 한다.

## 8. Normal Ending

충분한 우주선 파편과 고급 자원을 모으면 우주선을 복원할 수 있다.

```
Leave Ice Cat Planet?
```

이것이 기본 엔딩이다. 플레이어는 떠나지 않고 계속 플레이할 수도 있다.

**중요**: 이 엔딩은 실패도 차선도 아니다. 살아남아 돌아가는 것은 Level 0에서 세운
목표의 완수다. True Ending을 못 본 사람이 손해 봤다고 느끼게 만들지 않는다. `[확정]`

## 9. True Ending — Penguin Revenge

Level 3 이후 곳곳에 숨긴 Lore를 통해 플레이어가 점차 알게 되는 것:

```
1. 냥파편은 엄청난 잠재력을 가진 물질이다.
2. 고양이 문명은 지구 기술 수준을 훨씬 뛰어넘었다.
3. 그들은 공간 이동과 물질 복제 기술을 가지고 있었다.
4. 이 기술을 복원하면 탈출보다 훨씬 많은 일을 할 수 있다.
5. 펭귄들의 위치를 찾아낼 가능성이 있다.
6. Grim은 복수할 수 있다는 사실을 깨닫는다.
```

경로:

```
냥파편 연구 → 고대 기술 복구 → Teleport → Matter Replicator
→ Cat Replicator → Space Beam → 우주선 개조 → 펭귄 행성 좌표
```

### 복수도 자동화한다 `[확정]`

```
Ice Cat Planet
      │ Teleport
      ▼
Penguin Planet
```

Grim이 펭귄 행성에 도착해 Teleport Gateway를 설치한다. 그 뒤:

```
냥파편 → Cat Replicator → Space Beam을 든 고양이
→ 복제 → 복제 → 복제 → 고양이 자동화 군단
```

**이 시스템 자체를 공장으로 만든다.** 최종전은 전투가 아니라 생산 라인 설계다.

최종 화면:

```
REVENGE COMPLETE

PENGUIN PLANET AUTOMATION
100%
```

펭귄 행성을 파괴하는 것보다 **고양이 산업단지로 바꿔버리는 것**이 이 게임의 정체성에
맞다.

## 10. True Ending 이후 `[초안]`

```

```

펭귄 행성을 직접 플레이하는 Post-game 또는 DLC. Ice Cat Planet보다 혹독한 환경,
새로운 자동화 문제, 새 자원, 새 펭귄 시스템.

**지금 구현하지 않는다.** 본편 완성 이후의 영역이며 현재 우선순위는 P4다.

## 11. Lore를 어떻게 전달할 것인가 `[질문]`

이 문서에서 가장 안 정해진 부분이다. 후보:

| 방식 | 장점 | 위험 |
|---|---|---|
| 유적의 벽화·기록 | 탐험 보상과 결합 | 읽지 않고 지나칠 수 있다 |
| 구한 고양이가 반응 | 고양이에게 역할이 하나 더 생긴다 | 말하는 고양이는 톤을 바꾼다 |
| 냥파편 분석 결과 | 연구 진행과 자연스럽게 결합 | 텍스트 덩어리가 되기 쉽다 |
| 환경 자체 | 가장 우아함 | 만들기 가장 비싸다 |

**결정 전 원칙 하나**: Motorio는 텍스트를 읽는 게임이 아니다. Lore는 읽지 않아도
플레이에 지장이 없어야 하고, 읽은 사람에게만 True Ending이 열린다.
