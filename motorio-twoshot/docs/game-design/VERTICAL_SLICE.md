# VERTICAL_SLICE — 첫 30분

`../../VISION.md`가 단일 원본이고, 완료 조건은 `../../GOAL.md`에 있다.

## 1. 시간 예산 `[초안]`

30분은 상한이 아니라 **설계 목표**다. 숙련자는 더 빨리, 처음 하는 사람은 40분쯤
걸릴 것으로 본다. 아래 수치는 **처음 하는 사람 기준**이다.

| 구간 | 도달 시각 | 길이 | 이 구간이 파는 것 |
|---|---|---|---|
| 0 · 추락과 각성 | 0:00 | 2분 | "나 얼어 죽겠다" |
| 1 · 긴급기지 설치 | 0:02 | 3분 | 안전한 원이 생긴다 |
| 2 · 첫 외출과 Heatstone | 0:05 | 5분 | 밖은 값이 든다 / 연료를 넣으면 원이 커진다 |
| 3 · 첫 밤 | 0:10 | 3분 | 밤은 금지가 아니라 비싼 것이다 |
| 4 · 첫 고양이 구조 | 0:13 | 5분 | **Aha 1 — "먀?"** |
| 5 · 고양이 배치와 첫 자동 채굴 | 0:18 | 4분 | **Aha 2 — 내가 없어도 쌓인다** |
| 6 · 구리 발견 | 0:22 | 3분 | 새 재료 = 새 시스템의 입장권 |
| 7 · Conveyor와 자동 라인 | 0:25 | 5분 | **Aha 3 — 공장이 돈다** |
| 완료 | 0:30 | | |

**핵심 마일스톤 두 개** (GOAL.md의 검증 질문에 직접 대응):

- **첫 고양이가 일을 시작하기까지: 약 18분**
- **첫 컨베이어가 자원을 나르기까지: 약 27분**

`[질문]` 18분이 첫 고양이까지 너무 긴가? 짧게 만들면 Level 0의 "얼어 죽겠다"가
충분히 각인되지 않고, 길게 만들면 이탈한다. 실측 후 조정한다. 첫 후보 조정 폭은
±4분이며, 줄인다면 3번 구간(첫 밤)을 선택 사항으로 만드는 쪽이다.

## 2. 튜토리얼 흐름 — 무엇을 어떻게 가르치는가

**원칙**: 문장으로 가르치지 않고 **상황으로 가르친다.** 이 저장소의 기존 구현이
"행동형 빠른 시작"으로 이미 검증한 방식이다.

| 배워야 할 것 | 어떻게 가르치는가 | 문장으로 가르치면 생기는 일 |
|---|---|---|
| 이동 | 추락 지점과 키트가 떨어져 있다 | "WASD로 이동하세요" 배너 |
| 체온이 준다 | 화면 가장자리가 얼고 게이지가 눈에 띄게 준다 | "체온에 주의하세요" |
| 기지가 안전하다 | 기지 안으로 들어가면 체온이 **오른다** | "기지에서 체온이 회복됩니다" |
| 연료 → 반경 | 넣는 순간 원이 눈에 보이게 넓어진다 | "+3 반경" 토스트 |
| 채굴 | 곡괭이를 주우면 광맥이 반짝인다 | "광맥을 클릭하세요" |
| 밤 | 하늘이 어두워지고 감소가 빨라진다 | "밤이 되었습니다" |
| 고양이 구조 | 얼음 안에 실루엣이 보인다 | "얼어붙은 고양이를 발견했습니다!" |
| 고양이 배치 | 들고 있으면 놓을 수 있는 칸이 빛난다 | "광맥 위에 놓으세요" |
| 벨트 | 고양이가 걷는 시간이 눈에 띄게 길다 | "벨트로 효율을 높이세요" |

**가장 중요한 줄은 마지막 줄이다.** 벨트를 주기 전에 플레이어가 *직접* "얘 왜 이렇게
오래 걸어다니지"라고 느껴야 한다. 그 짜증이 없으면 벨트는 해결이 아니라 새 장난감일
뿐이고, Aha 3이 죽는다.

`[확정]` 튜토리얼 중에도 시간과 체온은 흐른다. 안전한 튜토리얼 상자 안에서 배우면
배운 것이 "규칙"이 아니라 "설명"이 된다.

## 3. 구간별 설계

### 구간 0 — 추락과 각성 (0:00~0:02)

```
추락 → 기절 → 깨어남 → 체온 30 → 화면 가장자리에 성에
```

`[질문]` 오프닝 연출의 형태(플레이 가능한 추락 / 정지 화면 / 바로 각성).
`WORLD_AND_STORY.md` §2의 같은 질문과 연결된다.

플레이어가 처음 보는 것은 **체온계**여야 한다. 이 게임이 무엇에 대한 게임인지
한 화면으로 말하는 유일한 기회다.

### 구간 1 — 긴급기지 (0:02~0:05)

```
주변에서 긴급생존키트 발견 → 조사 → 긴급기지 키트 획득 → 설치
→ 기지 주변에 Heat Zone 생성
```

**설치 위치를 플레이어가 고른다.** 자동 설치하지 않는다 — 이 게임의 첫 결정이
"내 세계의 중심을 어디로 할 것인가"라는 점이 뒤의 모든 확장에 의미를 준다.

`[초안]` 다만 완전 자유는 첫 5분에 과한 부담이다. 몇 칸 범위 안에서 고르게 하는
절충을 검토한다.

설치 직후 Energy Torch, Pickaxe, Emergency Shelter를 순서대로 발견한다.
셋 다 **줍는 물건**이지 제작물이 아니다. 아직 제작 시스템을 가르칠 때가 아니다.

### 구간 2 — 첫 외출과 Heatstone (0:05~0:10)

```
Torch를 기지에서 충전 → 제한 시간 동안 외부 탐색
→ Heatstone 광맥 발견 → 손 채굴 → 기지로 운반 → 공급
→ 온기 반경이 넓어진다
```

**이 구간이 Level 0 전체의 요약이다.** 나갔다 돌아오는 한 번의 호흡을 여기서 완성한다.

`[확정]` 연료를 넣었을 때 반경이 **눈에 보이게** 커져야 한다. 숫자가 아니라 원이
자란다. 이 인과가 이 게임 전체의 척추다(`CORE_LOOP.md` §5).

`[질문]` Heatstone을 직접 채굴할지, 채굴물을 기지에서 한 번 가공할지.
직접 채굴이 첫 10분에는 훨씬 명료하지만, 기존 `motorio-oneshot`은 가공 단계
(수정 → 교환기 → 에너지결정)를 두어 초반에 설비 하나를 더 가르친다.
Vertical Slice에서는 **직접 채굴을 우선 시도**한다 — 가르칠 것이 하나 적다.

### 구간 3 — 첫 밤 (0:10~0:13)

```
해가 진다 → 체온 감소 가속 → 시야 감소
→ 선택: Shelter에서 취침 / 위험을 감수하고 계속
```

`[확정]` **Hard Lock 없음.** "밤에는 나갈 수 없습니다"는 없다. 밤에 나가는 것은
가능하고, 비싸고, 가끔은 옳은 선택이어야 한다.

이 구간이 짧은 것은 의도적이다. 첫 밤은 **가르치는 밤**이고, 두 번째 밤부터
플레이어가 스스로 판단한다.

### 구간 4 — 첫 고양이 구조 (0:13~0:18) ★ Aha 1

```
탐색 중 얼음 덩어리 발견 → 안에 실루엣 → 들어 올림
→ 기지로 운반 (양손이 막혀 채굴 불가)
→ Heat Zone 안에 내려놓음 → 얼음이 녹는다
→ 눈을 뜬다 → Grim을 바라본다 → "먀?"
```

**이 30분에서 가장 공들여야 할 8초다.**

설계 지침:
- 해동은 즉시 끝나지 않는다. 몇 초 걸리고, 그동안 플레이어는 **볼 수밖에 없다.**
- 이 순간에 UI를 띄우지 않는다. 자원 획득 토스트도, 튜토리얼 배너도 없다.
  `+1 Cat`이라고 쓰는 순간 고양이는 유닛이 된다.
- 안고 오는 동안 채굴을 못 하는 것은 불편이 아니라 **비용**이다. 데려오기로 한
  결정에 무게가 실린다.
- 소리가 절반이다. 얼음이 갈라지는 소리, 그리고 "먀?".

`[질문]` 첫 고양이를 발견하는 위치를 고정할지. 고정이면 연출을 정확히 설계할 수 있고,
무작위면 발견이 진짜 발견이 된다. **Vertical Slice에서는 고정을 권한다** —
30분 안에 반드시 일어나야 하는 사건을 무작위에 맡기지 않는다.

### 구간 5 — 배치와 첫 자동 채굴 (0:18~0:22) ★ Aha 2

```
고양이를 들어 광맥 위에 놓는다 → 채굴 시작
→ 자원을 직접 기지로 운반 → 다시 돌아옴 → 반복
→ 플레이어가 다른 일을 하는 동안에도 자원이 쌓인다
```

`[확정]` 첫 자동 채굴은 **손 채굴보다 빠르지 않다.** 같은 속도로 둔다.
빨라진 것이 아니라 **내가 없는 곳에서 일어나는 것**이 요점이다(`CORE_LOOP.md` §7).

이 구간에서 플레이어는 고양이가 걷는 데 시간을 많이 쓰는 것을 본다.
**그 관찰이 구간 7의 재료다.** 여기서 그 비효율을 고쳐 주지 않는다.

### 구간 6 — 구리 발견 (0:22~0:25)

```
넓어진 온기 반경 밖에서 구리 광맥 발견 → 채굴 → 새 제작 항목 해금
```

`[확정]` 구리는 **온기 반경이 한 번 이상 확장된 뒤에 닿는 거리**에 둔다.
그래야 "연료를 넣어 반경을 넓힌 것"이 보상으로 돌아온다. 기존 구현의 링 배치
(수정 4~9.5칸, 구리 11~17칸)가 이 관계를 이미 구현하고 있어 참고 가치가 있다.

### 구간 7 — Conveyor와 자동 라인 (0:25~0:30) ★ Aha 3

```
구리로 Conveyor 제작 → 광맥에서 기지까지 벨트를 놓는다
→ 고양이가 걷기를 멈추고 채굴만 한다
→ 자원이 저절로 흐른다
```

```
이전                              이후
고양이: 캔다 → 든다 → 걷는다       고양이: 캔다
        → 놓는다 → 돌아온다        벨트:  ▶▶▶▶▶▶▶▶▶ Base
```

**이 순간의 연출**: 첫 아이템이 벨트를 타고 기지에 도착할 때까지 카메라가 따라가거나,
최소한 플레이어가 그 여정을 한 번은 끝까지 볼 이유를 준다. 벨트를 깔고 바로 다른 일을
하게 두면 이 게임에서 가장 중요한 장면을 아무도 안 본다.

**Vertical Slice는 여기서 끝난다.** 완전 자동 생산라인 **한 개**면 충분하다.

## 4. 해금 순서 `[초안]`

```
0분   (없음)              — 줍는 것만 있다
2분   긴급기지            — 설치 가능
3분   Torch / Pickaxe / Shelter — 줍기
5분   손 채굴             — Pickaxe 획득으로
8분   기지 연료 공급      — 첫 Heatstone으로
13분  고양이 들기/놓기    — 첫 얼음 고양이 발견으로
22분  제작 시스템         — 첫 구리로
25분  Conveyor            — 구리 보유량 충족으로
```

**해금 트리거는 시간이 아니라 사건이다.** "5분이 지나면 열림"이 아니라
"첫 구리를 손에 쥐면 열림". 기존 구현이 `MACHINE_UNLOCK_ITEM`으로 쓰는 방식이며
좋은 패턴이다 — 플레이어가 원인을 안다.

`[확정]` 첫 프레임에 회색 잠긴 슬롯을 늘어놓지 않는다. 핫바는 플레이어가 벌면서
왼쪽에서 오른쪽으로 자란다.

## 5. 핵심 Aha Moment 세 개

| # | 순간 | 시각 | 파는 감정 | 죽는 방식 |
|---|---|---|---|---|
| 1 | 고양이가 눈을 뜬다 | 18분 | 나는 혼자가 아니다 | 토스트 UI, 즉시 해동, 무음 |
| 2 | 내가 없는데 자원이 쌓인다 | 21분 | 시간이 두 배가 됐다 | 첫 채굴기가 손보다 빠름 |
| 3 | 벨트가 자원을 나른다 | 27분 | 공장이 산다 | 걸어다니는 불편을 먼저 안 겪음 |

**GOAL.md의 검증 질문은 1번과 3번을 직접 겨냥한다.** 2번은 그 둘을 잇는 다리이고,
사실상 이 슬라이스에서 가장 조용히 중요한 순간이다 — 1번이 감정이고 3번이 시스템이라면
2번은 감정이 시스템으로 바뀌는 지점이다.

Grim 스프라이트·저장·터치 조작·한글 폰트 서브셋.

## 7. 이 슬라이스가 답해야 할 것

30분을 만들고 나서 물어야 할 질문은 "조건을 다 채웠는가"가 아니다.

1. 고양이가 눈을 뜨는 순간에 **사람이 잠깐 멈추는가**
2. 벨트를 깔기 전에 **고양이가 걷는 것이 답답한가**
3. 벨트를 깔고 나서 **바로 두 번째를 깔고 싶은가**
4. 30분이 지났을 때 **31분째를 하고 싶은가**

4번만이 진짜 답이다. 나머지 셋은 4번이 왜 그런지를 설명한다.

**재미없다는 결론도 성공한 검증이다.** 큰 것을 짓기 전에 알아낸 것이기 때문이다.
