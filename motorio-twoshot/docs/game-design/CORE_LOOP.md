# CORE_LOOP — 다섯 시스템이 서로를 먹여 살리는 방식

`../../VISION.md`가 단일 원본이다. 이 문서는 그중 Pillar 1~3이 실제로 어떻게 맞물리는지를
푼다.

---

## 0. 한 장짜리 요약

Motorio에는 다섯 개의 시스템이 있다. 중요한 것은 각각이 아니라 **화살표**다.

```
        ┌──────────────────────────────────────┐
        │                                      │
        ▼                                      │
     EXPLORE ──발견──▶ CAT ──노동력──▶ AUTOMATION
        ▲                ▲                  │
        │                │                  │
     시야/체온        살 수 있는 곳        생산량
        │                │                  │
        └──── HEAT ◀─────┴──── LOGISTICS ◀──┘
                 ▲                  │
                 └───── 연료 ───────┘
```

읽는 법:

- **탐험**이 새 자원과 얼어붙은 고양이를 찾는다.
- **고양이**가 노동력이 되지만, 따뜻한 곳에서만 안정적으로 일한다.
- **자동화**가 생산량을 만들지만, 고양이나 전력을 요구한다.
- **물류**가 생산물을 기지로 나른다. 이것이 없으면 자동화는 고양이의 걸음 속도에 묶인다.
- **열**이 그 전부가 존재할 수 있는 공간을 만들고, 자기 자신은 연료를 먹는다.

**닫힌 고리다.** 열을 넓히려면 연료가 필요하고, 연료를 캐려면 고양이가 필요하고,
고양이가 일하려면 열이 필요하다. 플레이어가 하는 일은 이 고리를 한 바퀴씩 크게 돌리는
것이다.

## 1. 각 시스템이 남에게 주는 것과 요구하는 것

| 시스템 | 주는 것 | 요구하는 것 | 없으면 |
|---|---|---|---|
| Explore | 새 자원 위치, 고양이, 마을, 파편 | 체온, 시야, 시간 | 게임이 한 화면으로 줄어든다 |
| Heat | 살 수 있는 공간, 고양이 작업 가능 구역 | 연료(에너지 광물) | 아무것도 밖에 지을 수 없다 |
| Cat | 노동력, 채굴, 운반 | 온기, 식량, 구조 행위 | 모든 것을 플레이어가 손으로 한다 |
| Automation | 생산량, 병렬성 | 고양이 또는 전력, 재료 | 생산이 플레이어 접속 시간에 비례한다 |
| Logistics | 거리의 제거 | 재료(구리), 배치 설계 | 자동화가 걸음 속도에 묶인다 |

이 표에서 가장 중요한 줄은 **Logistics**다. 벨트가 없을 때 고양이는 채굴하고, 들고,
걸어가고, 내려놓고, 돌아온다. 벨트가 생기면 고양이는 **채굴만** 한다. 생산량이 오르는
것이 아니라 **고양이가 하는 일의 종류가 바뀐다.** 이것이 Pillar 4의 교과서적 사례이고,
Vertical Slice가 반드시 여기까지 도달해야 하는 이유다.

## 2. Early Game Loop — Level 0~2

목표 감정: *"나 얼어 죽겠다"* → *"얘가 나 대신 일하네?"* → *"자동으로 돌아간다"*

```
   ┌──────────────────────────────────────────────┐
   │                                              │
   ▼                                              │
 나간다 ──▶ 캔다 ──▶ 체온이 떨어진다 ──▶ 돌아온다 ──┘
                                          │
                                          ▼
                                    기지에 연료를 넣는다
                                          │
                                          ▼
                                    온기 반경이 넓어진다
                                          │
                                          ▼
                                  더 멀리 나갈 수 있다
```

초반 루프의 리듬은 **나갔다 돌아오는 것**이다. 한 번의 외출이 하나의 호흡이고,
그 길이를 정하는 것은 체온이다. 체온계는 타이머가 아니라 **밧줄**이다 —
얼마나 멀리 갈 수 있는지가 아니라 얼마나 오래 밖에 있을 수 있는지를 정한다.

고양이가 들어오면 루프의 모양이 바뀐다.

```
 나간다 ──▶ 얼어붙은 고양이를 발견 ──▶ 안고 돌아온다 ──▶ 녹인다 ──▶ 배치한다
                                                                    │
                                                                    ▼
                                                       내가 없어도 자원이 쌓인다
```

이 순간부터 플레이어는 **자기 시간과 고양이 시간을 따로 쓴다.** 밖에 나가 있는 동안에도
기지의 생산이 멈추지 않는다는 것 — 이것이 첫 번째 Aha이고, 게임이 자동화 게임이 되는
지점이다.

## 3. Mid Game Loop — Level 3~6

목표 감정: *"저 눈안개 너머에는 뭐가 있지?"* → *"내 기지가 행성을 먹고 있다"*

```
 탐험 ──▶ 자원 지대 / 마을 발견
   ▲               │
   │               ▼
   │        Heat Network 연장
   │               │
   │               ▼
   │        전초기지 설치 ──▶ 고양이 배치 ──▶ 생산
   │                                          │
   └────────── 물류로 본기지에 연결 ◀──────────┘
```

중반의 단위는 **한 채의 건물이 아니라 한 곳의 전초기지**다. 플레이어가 내리는 결정도
"채굴기를 어디 놓지"에서 "이 자원 지대를 통째로 살릴 만한가"로 커진다.

중반의 진짜 문제는 생산량이 아니라 **거리**다. 열을 어떻게 멀리 보낼 것인가,
자원을 어떻게 멀리서 가져올 것인가. Heat Relay와 물류가 같은 문제의 두 얼굴이고,
그래서 이 둘은 같은 시기에 등장해야 한다.

## 4. Late Game Loop — Level 7~10

목표 감정: *"이제 내가 이 행성의 규칙을 바꾼다"* → *"복수조차 자동화했다"*

```
 고대 지역 탐험 ──▶ 냥파편 발견 ──▶ 연구
                                     │
                                     ▼
                       기존 자동화의 한계를 깨는 기술
                       (Teleport / Replicator / Zero-point)
                                     │
                                     ▼
                       규모가 한 자릿수 뛴다 ──▶ 새로운 병목
                                     │
                                     ▼
                              우주선 복원 / 펭귄 좌표
```

후반 루프의 핵심은 **기존 루프를 지우는 것이 아니라 접는 것**이다. Teleporter가 생겨도
벨트는 사라지지 않는다. 벨트로 풀던 문제를 다른 층위에서 다시 만나게 한다 —
"이 자원을 저기로 어떻게 옮기지"가 "이 행성의 생산을 저 행성으로 어떻게 옮기지"가 된다.

**냥파편 기술의 등장 조건**은 시간이 아니라 경험이다.

| 플레이어가 충분히 겪은 것 | 그 뒤에 열리는 것 |
|---|---|
| 벨트로 물류를 짜 봤다 | Teleporter |
| 전력망의 병목을 겪어 봤다 | Zero Point Energy |
| 고양이를 직접 구하고 배치해 봤다 | Cat Replicator |
| 손으로 채굴 → 기계 채굴을 겪었다 | Space Beam |

규칙을 깨는 보상은 **규칙을 배운 사람에게만 의미가 있다.** 초중반에 강력한 냥파편 기술을
주면 그 앞의 모든 시스템이 무의미해진다.

## 5. Heat — 이 게임의 척추

열은 다섯 시스템 중 유일하게 **다른 넷 전부와 직접 연결된 것**이다.

- 탐험: 온기 반경 밖에서 체온이 깎인다 → 탐험 거리의 상한
- 고양이: 따뜻한 곳에서만 안정적으로 일한다 → 자동화 가능 영역의 상한
- 자동화: 연료를 태우는 설비가 곧 열원 → 생산과 난방이 같은 자원을 두고 경쟁
- 물류: 열을 멀리 보내는 것 자체가 물류 문제 → Heat Pipe는 벨트의 사촌

**설계 지침**: 새 시스템을 붙일 때 "이것이 Heat와 어떻게 연결되는가"에 답하지 못하면
그 시스템은 Motorio의 것이 아니다. 이 질문 하나가 스코프를 지키는 가장 싼 도구다.

### 열이 절대 하지 말아야 할 것

- 열 부족으로 **되돌릴 수 없는 상태**를 만들지 않는다. 연료가 떨어져 기지가 꺼지고
  다시 켤 방법이 없으면 그건 난이도가 아니라 세이브 파괴다.
- 열을 **화폐로 쓰지 않는다.** 열로 기계를 사면 열은 공간이 아니라 숫자가 된다.
  기계는 재료로 산다.

## 6. Cat — 노동력이자 감정

고양이는 두 역할을 겸한다. 둘 중 하나만 남으면 이 게임은 실패한다.

| 역할 | 설계상 의미 | 무너지면 |
|---|---|---|
| 노동력 | 자동화의 단위. 배치·식량·이동이 최적화 대상 | 감정 없는 유닛 = 스킨 씌운 Factorio |
| 구조 대상 | 발견하고 구하는 것이 보상 | 노동력만 남으면 왜 고양이여야 하는지가 사라진다 |

**따라서 고양이를 얻는 경로는 반드시 세계 안에 있어야 한다.** 상점이나 뽑기로 고양이를
얻게 하면 "구조"라는 동사가 사라지고 Pillar 3이 무너진다.
(기존 구현에 슬롯머신이 있다 — `CURRENT_STATE.md`의 충돌 항목 1번을 볼 것.)

고양이의 요구사항은 압력이지 벌이 아니다. 배고픈 고양이는 느려지되 죽지 않는다.
추운 곳의 고양이는 일을 멈추되 사라지지 않는다. **되돌릴 수 있는 실패**만 쓴다.

## 7. Automation — 병렬성이지 속도가 아니다

첫 번째 채굴기는 플레이어보다 빨라서는 안 된다.

```
손 채굴  10초에 1개
채굴기   10초에 1개   ← 같다. 의도적으로.
```

같은 속도인데도 의미가 있는 이유는 **채굴기는 내가 없는 곳에서 돌기 때문**이다.
첫 자동화가 "빨라졌다"로 읽히면 그다음은 더 빠른 채굴기밖에 없고, 그건 금지 사항 5.2다.
"두 곳에서 동시에 일어난다"로 읽히면 그다음은 세 곳, 열 곳, 그리고 그것을 잇는 물류다.

*(이 원칙은 기존 `motorio-oneshot`이 이미 정확히 구현했고, 그대로 가져올 가치가 있다.)*

## 8. Logistics — 거리를 지우는 시스템

물류는 생산량을 늘리는 장치가 아니라 **거리를 지우는 장치**다.

```
벨트 이전                          벨트 이후
고양이: 캔다 → 든다 → 걷는다        고양이: 캔다
        → 놓는다 → 돌아온다         벨트:   나머지 전부
```

물류 단계의 순서는 거리의 크기를 따라간다.

| 거리 | 도구 | 등장 시기 |
|---|---|---|
| 한 화면 안 | 벨트, 분배기 | Level 2 |
| 전초기지 ↔ 본기지 | 장거리 벨트, 열차 또는 그에 준하는 것 `[초안]` | Level 5~6 |
| 행성 규모 | Gravity Logistics `[초안]` | Level 8+ |
| 행성 간 | Teleporter | Level 9+ |

각 단계는 **앞 단계로는 풀 수 없는 거리**가 생겼을 때 등장한다. 새 물류를 먼저 주고
그것을 쓸 이유를 나중에 만들면 순서가 뒤집힌다.

## 9. 루프가 고장 나는 지점 — 미리 적어 두는 위험

| 위험 | 증상 | 방어 |
|---|---|---|
| 열이 그냥 자원이 됨 | 플레이어가 반경을 안 보고 숫자만 봄 | 반경을 항상 화면에 그린다. 열 소비를 UI 숫자가 아니라 원의 크기로 느끼게 한다 |
| 고양이가 유닛이 됨 | 이름·표정·구조 연출 없이 배치만 함 | 구조 연출을 자르지 않는다. 첫 고양이는 반드시 손으로 안고 온다 |
| 자동화가 속도 업그레이드가 됨 | 다음 티어 채굴기가 유일한 성장 | 각 Level에 새 동사를 요구한다 (Pillar 4) |
| 탐험이 자원 수집이 됨 | 눈안개 너머에 광맥만 있음 | 마을·파편·유적처럼 **자원이 아닌 것**을 섞는다 |
| 물류가 선택이 됨 | 벨트 없이도 충분히 굴러감 | 거리가 실제로 아프게 설계한다. 고양이 걸음은 느려야 한다 |
