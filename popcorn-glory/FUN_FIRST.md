# Fun First — 재는 기준

**한 가지 기계, 한 가지 돈, 한 가지 행동.** 글로 가르치지 않는다: 첫 화면의 모양과 누른 순간의
반응이 설명이다(AGENTS.md, 2026-08-19 방침). 아래 목표는 Step 02의 세 실험이 각자 **자기 숫자**로
구체화하고, Step 04에서 실제 입력으로 잰다. 지금 값은 모두 **가설**이다.

## 네 순간

| 시각(활동 시간) | 사람이 느껴야 하는 것 | 기록으로 재는 것 (자동) | 통과선 (가설) |
|---|---|---|---|
| **10초** | 무엇을 누르면 되는지 안다 | 첫 화면 → 첫 주 행동 입력 시각, 입력 → 화면 반응 지연 | 첫 입력 ≤ 10초, 반응은 **같은 프레임**(≤ 1프레임) |
| **30초** | 보상을 받았다 | 첫 수입 시각, 첫 업그레이드가 살 수 있게 된 시각 | 첫 수입 ≤ 5초, 첫 업그레이드 가능 ≤ 30초 |
| **60초** | 기계가 눈에 띄게 바뀌었다 | 첫 업그레이드 구매 시각, 그 뒤 화면 변화(기계 크기·색·팝 수) | 구매 ≤ 60초, 변화는 정지 화면 두 장으로 구분 가능 |
| **180초** | 하나 더 바꾸고 싶다 | 업그레이드 수, 3:00 시점 다음 업그레이드까지 남은 시간, 가장 긴 강제 대기 | 업그레이드 ≥ 3, 다음 것까지 ≤ 20초, 강제 대기 ≤ 15초, 막다른 길 0 |

## 활동 시간

- 시계는 **게임이 보이고 움직일 때만** 간다. 탭이 숨으면 멈추고, 한 프레임은 최대 0.25초로 자른다
  (숨었다 돌아온 첫 프레임이 몇 분을 한 번에 들이지 않게).
- 모든 기록의 시각은 이 활동 시간이다. 벽시계는 쓰지 않는다.

## 기록 (로컬 전용)

`{t_ms, type, data}` 한 줄씩. 서버로 보내지 않고, 저장하지 않으며, `?dev=1`에서만 JSON으로 내려받는다.

| type | 언제 |
|---|---|
| `input` | 주 행동 입력(탭·누름·뗌) |
| `pop` / `earn` | 팝콘이 터짐 / 돈이 들어옴 |
| `upgrade` | 업그레이드 구매(단계·가격) |
| `milestone` | 위 네 순간 중 하나를 넘음 |
| `idle` | 5초 이상 입력이 없던 구간(시작·길이) |
| `reset` | 다시 시작 |

## 사람 점수 (1–5, 건너뛰기 가능)

1. 설명 없이 알았다 2. 업그레이드가 짜릿했다 3. 다음 변화가 궁금했다 4. 3분 뒤에도 계속하고 싶었다

빈칸은 0점이 아니다. **AI·스크립트 플레이어의 관찰은 객관 수치로만 적고, 사람의 즐거움으로 적지 않는다.**
