# Step 35 블라인드 첫 사용 — 숟가락 손 마무리 (0.35.0, 로컬 export)

이슈 #148의 5번 요구: 선택 동작을 처음 보는 플레이어가 어떻게 받아들이는지, 헷갈린 점을 적고, 잡일처럼 느껴지면 지운다.

## 방법
- 도구: `tools/blind/` (Step 08). 새 컨텍스트의 AI 플레이어 둘(A, B). 각자 프롬프트는 README의 것 그대로이고 'five minutes'로만 바꿨다. 숟가락이나 맛에 대한 말은 하지 않았다.
- 빌드: 배포 전 로컬 export 0.35.0. `docs/`를 `python3 -m http.server`로 서빙했다.
  - A: `game-9955576c4a47.pck`. B: `game-1713e48076e2.pck`(A 뒤에 숟가락 그림과 손실 효과를 고친 빌드, 아래).
- 시작점: `?scene=flavors#factory`. 맛이 열린 시점의 공장을 플레이어 명령으로 지은 것이다.
  - 간판 4, 포장대 3, 냄비 둘, 호퍼, M12, 분무기(치즈), 코팅기(카라멜).
  - 손이 20번 팝한 상태(숟가락 열림), 1,500코인.
  - 저장하지 않는다. 측정용 고정 장면이고 플레이가 아니다.
- 각 세션은 실제 5분, 400×860, 터치.
- 블라인드 조건은 지시와 사후 감사로 지켰다(샌드박스 아님). `audit.txt`: A 65개, B 149개 호출, 걸린 것 0.
  - 감사 도구가 이 저장소의 경로를 '자기 것'으로 알아보도록 허용 목록을 넓혔다(`tools/blind/audit.py`). 그전에는 플레이 도구 자체를 걸었다.
- 부하: A 시작 부하 약 12–15(다른 세션의 빌드), B 시작 1.9. `run*/load.txt`.

## 해석과 한 일
- **잡일처럼 느껴졌는가: 아니다.** 아무도 쓰지 않았으므로 잡일이 될 수 없었다. 이 동작은 냄비의 판정을 바꾸지 않고, 쓰지 않아도 기계가 그대로 만든다(D-43).
  - 그래서 지우지 않았다. 대신 '발견되지 않는 선택 동작'으로 기록한다.
- A 뒤에 고친 것 (B는 고친 빌드로 했다):
  1. 손실 효과를 연기에서 맛 색의 부스러기로 바꿨다. 연기는 '탄다'로 읽혔다.
  2. 숟가락을 금색 원판에 흰 테두리, 진한 국자로 바꿨다. 흰 원에 옅은 놋쇠 숟가락은 눈에 띄지 않았다.
  3. 20초 규칙의 시계를 고쳤다. 판이 2–10초만 드럼에 있으므로, 판마다 다시 세던 시계는 20초에 닿지 않았다. 이제 손이 한 번도 쓰지 않은 동안 숟가락이 나와 있던 시간을 모두 더한다.
- B는 고친 숟가락을 보았지만 돋보기나 거품기로 읽었고 눌러 보지 않았다. 발견성은 아직 낮다. AI 플레이어는 5분에 명령 수십 개로, 사람의 손 속도가 아니다.
- 다음: 냄비 거절의 연기를 탄 팝과 구별하고, 숟가락이 '부을 수 있는 것'으로 읽히게 하는 일. Step 44(사용성)와 Step 47(블라인드 초보·중반·전체 공장)에서 사람 기준으로 다시 본다.
