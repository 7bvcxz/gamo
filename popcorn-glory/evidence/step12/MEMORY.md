`_emscripten_glFenceSync` 458KB · `_emscripten_glGenBuffers` 458KB · `_emscripten_glGenVertexArrays` 458KB (모두 `MainLoop_runner` 아래).

해석: Emscripten의 GL 객체 번호표는 번호를 다시 쓰지 않는다. Godot 호환 렌더러는 다각형을 다시 그릴 때마다 버퍼·VAO를 새로 만들고 지운다. 그래서 번호표 배열이 한 칸씩 계속 길어진다.
놀이 화면은 두 그리기 층을 매 프레임 다시 그린다(`app/play_view.gd`). 선택 화면은 다시 그리지 않으므로 늘지 않는다.
숨은 탭은 그리지 않으므로 늘지 않는다. 고치는 길은 움직이지 않는 그림을 따로 떼어 바뀔 때만 다시 그리는 것이다.
