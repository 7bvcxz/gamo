# Step 36 증거 — 손님 다섯, 취향, 가게의 인기 (0.36.0)

모두 실제로 실행해서 얻은 것이다. 이 폴더는 게임 팩에 들어가지 않는다(`evidence/.gdignore`).

## 영상 (실제 브라우저, 소리 포함)
- `cast_p720.webm`(720×1280 터치), `cast_desktop.webm`(1280×800), 각 약 1분 54초.
  - 촬영한 one-off 스펙(`zz_av36`)은 쓰고 지웠다.
  - 가게를 손가락으로 짓는다(간판 4, 포장대 3, 냄비 둘, 호퍼, 분무기, 코팅기).
  - 약 70초를 실제 시간으로 돌린다. 손이 냄비를 누른다.
  - 그다음 카드의 층 멈춤으로 부엌을 멈추고 25초를 더 돌린다.
- 영상은 소리가 시작되기 15초 전부터 잘랐다. 최대 −5.5 dB로 소리가 있다.
- 수치(`cast_*_stats.json`): 두 화면 모두 같았다.
  - 70초 동안: 판매 21, 그중 즐겁게 받은 손님 21. 버터 팬 7–8, 단것 좋아 5, 바쁜 사람 6, 간식 사냥꾼 6. 인기 50.4 → 54.6.
  - 부엌을 멈춘 25초: 선반에 남은 봉지로 9개를 더 팔았다. 아무도 떠나지 않았다(선반이 비기 전).
  - 떠나는 장면은 브라우저 시험 `customers36`이 확인한다.
  - 보존은 맞고 잘못 준 봉지는 0이다.
- 부하는 `footage_load.txt`, 프레임 넷은 `strip_*.png`에 있다.
