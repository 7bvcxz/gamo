# CORE_LOOP — 손 한 번에서 공장까지 (Step 13)

## 1. 초 단위 고리 (손) [confirmed]

1. 큰 냄비를 **누르고 있는다** → 불꽃, 고리가 시계 방향으로 찬다, 지글 소리가 오른다(0.12.x 그대로).
2. **금색에서 뗀다** → 팝. 등급이 정해지고(완벽·좋음·덜 익음·늦음·탐), 그 등급만큼의 팝콘이 **실제 묶음(lot)**으로 원료 통에 들어간다.
3. 식는 시간(회색 고리)이 지나면 다시 누를 수 있다.

손의 몫은 '한 번 시도의 질'이다: 같은 단계의 기초 자동 냄비 하나보다 완벽한 팝 하나가 더 많고 더 좋은 팝콘을 만든다(`PROGRESSION` 4절).

## 2. 분 단위 고리 (흐름) [confirmed]

```
누르기·떼기 → 원료 통(아래→가운데) → 포장대가 봉지에 담음 → 선반(가운데→위) → 손님이 와서 주문 → 계산대가 건넴 → 돈
```

- 포장과 판매는 처음부터 **저절로** 돈다. 손은 냄비 하나에 집중한다. 포장에 손이 필요한 일곱 번의 탭은 없다.
- 돈은 계산대에서 봉지가 손님 손에 들어가는 순간 한 번 생긴다(`FACTORY_FLOW` 4절).
- 화면은 지금 막힌 곳을 그림으로 말한다: 원료 통이 비었으면 포장대가 쉰다, 선반이 비었으면 손님이 기다린다, 손님이 없으면 선반이 찬다.

## 3. 장관 고리 — B에 C의 정신을 얹는다 (Step 14) [proposal]

- 성공한 팝(완벽·좋음)이 냄비 위 **크레셴도 막대**에 낟알을 쌓는다. 완벽 = 2칸, 좋음 = 1칸, 실패는 쌓이지 않고 깎지도 않는다(벌하지 않는다).
- 막대가 차면 다음 팝이 **분수**가 된다: 더 큰 팝콘 소나기와 함께 덤 낟알(그 팝의 묶음 +50%, 실제 묶음으로)이 나온다.
- 단계에 따라 장관이 세 가지로 커진다: 한 번 팝 → 연쇄 송이 → 기쁨의 분수. 금색 표시와 누름 영역을 절대 가리지 않는다.
- 0.12.x의 B는 기본값으로 그대로 두고, 장관은 되돌릴 수 있는 설정(`?burst=1` → 결과가 좋으면 공장의 기본값)으로 비교한다.

## 4. 시간 단위 고리 (공장) [confirmed]

- 돈으로 세 층을 강화한다: 냄비(손의 묶음과 회복), 포장대(한 번에 몇 봉지, 얼마나 빨리), 가게(계산대 줄 수, 간판 = 손님이 얼마나 자주 오나).
- 자동 기계 40종을 칸에 놓는다. 기계는 실제로 물건을 옮기고 만들며, 켜져 있는 동안 유지비를 낸다.
- 맛(버터·카라멜·치즈·매콤·코코아)이 새 손님과 새 결정을 연다. 소식은 시장을 잠깐 바꾸고, 대회는 하고 싶을 때 하는 도전이다.

## 5. 결정이 생기는 자리

| 결정 | 맞바꿈 |
|---|---|
| 냄비 vs 포장 vs 가게 | 가장 느린 층이 전체를 정한다. 막힌 층을 화면이 보여 준다 |
| 손 vs 자동 | 손은 시도당 질, 자동은 쉬지 않는 병렬 생산 + 유지비 |
| 맛 | 카라멜은 비싸지만 느리고 어렵고, 치즈는 쉽고 빠르다. 손님마다 좋아하는 맛이 다르다 |
| 간판 | 손님을 더 자주 부르지만, 팔 물건이 없으면 기다리다 떠난다 |
| 소식 | 잠깐 특정 맛의 손님이 는다. 맞춰 바꿀지, 하던 대로 할지 |
