# 그림과 소리 (Step 05)

## 쓸 수 있는 도구 (Step 01 실측 + 이후 확인)

| 도구 | 상태 | 이 단계에서 |
|---|---|---|
| imagegen (OpenAI) | 2026-11-03 Windup 세션이 실제 호출에서 **HTTP 429 `credit_balance_exhausted`**를 받았다(아무것도 생성·청구되지 않음, 커밋 `00529de0`). 이 세션은 돈이 나가는 호출을 다시 시도하지 않았다 | 쓰지 않음 |
| TopView (영상·그림) | 이 세션에서 MCP 미인증, 모든 생성이 크레딧 차감 + 사용자 승인 필요 | 쓰지 않음 |
| Godot `Image.load_svg_from_string` | 있음(엔진 내장) | **SVG → 래스터 → 아틀라스** |
| ffmpeg 7.0.2 (libvorbis) | 있음 | **합성 WAV → Ogg** |
| Pillow · rembg · ImageMagick · Inkscape | 없음 | 필요 없게 만들었다 |

돈이 들지 않고, 같은 입력이면 같은 결과가 나오는 길만 썼다.

## 방향

- **따뜻한 버터 색 무대 위의 빨간 팝콘 수레.** 바탕은 버터(#FEE199), 기계는 빨강·크림·금, 선은 진한 갈색(#4D291A).
- 팝콘은 크림색 덩어리에 갈색 외곽선과 버터 얼룩 — 작게 그려져도 '팝콘'으로 읽히는 실루엣 세 가지(꽃·나비·버섯).
- 문장이 없다. 정보는 모양·색·소리로: 금색 = 좋다(완벽·업그레이드), 연기·낮은 소리 = 탔다, 음높이 상승 = 차오른다.
- 브랜드·캐릭터·기존 게임의 그림을 닮게 하지 않는다. 모든 원본은 이 저장소에서 손으로 썼다.

## 기계의 네 외형

기계는 여전히 도형으로 그린다(`art/machine_art.gd`) — 12단계 모두가 무언가를 더해야 하고, 업그레이드 버튼의 실루엣이 같은 그림이어야
하기 때문이다. 대신 네 외형으로 묶었다:

| 단계 | 외형 | 더해지는 것 |
|---|---|---|
| 0–2 | 클래식 수레 | 빨간 몸통·유리·지붕 → 차양 → 바퀴 |
| 3–5 | 카니발 | 지붕 전구 → 큰 별 → 깃발 줄 |
| 6–8 | 디럭스 | 금테 → 주전자 둘 → 금 바퀴 |
| 9–11 | 글로리 | 진홍 몸통·가로등 → 금 주전자 → 큰 왕관 별 |

Step 05에서 더한 것: 잉크 외곽선(몸통·지붕, 도형마다 polyline 하나), 위에서 오는 빛의 띠, 유리의 반사, 유리 안 팝콘 더미를 아틀라스
조각으로. 기계는 자기 노드에서 모양이 바뀔 때만 다시 그려지므로 이 장식은 프레임마다 비용이 없다.

## 스프라이트 (`art_src/*.svg` → `assets/atlas/sprites.png`)

| 이름 | 원본 | 쓰는 곳 |
|---|---|---|
| piece_a · piece_b · piece_c | 손으로 쓴 SVG 64×64 | 날아가는 팝콘(색을 곱해 금·갈색), 유리 안 더미 |
| kernel | 32×40 | B의 유리 안 낟알(열에 따라 밝아짐), C의 낟알 칸, B의 덜 익음 |
| coin | 64×64 | 돈 표시·업그레이드 가격·날아가는 동전 |
| sparkle | 48×48 | 완벽한 팝, 업그레이드 |
| smoke | 64×64 | B의 탐 |

- 빌드: `godot --headless --path popcorn-glory --script res://tools/build_atlas.gd` → `--import`. 래스터화 → 투명 영역 잘라내기 →
  선반 포장(256×128) → 가장자리 2픽셀 복제(선형 필터·밉맵이 이웃을 섞지 않게). `sprites.json`에 원본의 sha가 남고, 원본을 고치고
  다시 빌드하지 않으면 테스트가 실패한다(`test_assets.gd`).
- `art_src/`는 `.gdignore`로 팩에서 빠진다. 게임은 아틀라스 PNG 하나만 쓰므로 효과 조각이 모두 같은 텍스처다.
- 아틀라스가 없으면 그리는 쪽이 도형으로 되돌아간다(처음 clone한 상태에서도 열린다 — 아틀라스는 커밋되어 있다).

## 소리 (`tools/build_audio.py` → `assets/audio/*.ogg`, 합계 약 72KB)

| 이름 | 만드는 법 | 언제 |
|---|---|---|
| pop_1–3 | 노이즈 클릭 + 아래로 떨어지는 '퐁' | 팝마다(음높이 ±8%, A는 연타할수록 조금씩 높아짐) |
| coin | 종소리 두 번(E6→B6) | 돈이 들어올 때(작게) |
| upgrade | 종소리 네 음 상승(C5 E5 G5 C6) | 업그레이드 |
| sizzle | 저역 통과 노이즈, 0.2초 교차로 이음 없는 반복 | B를 누르고 있는 동안(열에 따라 음높이 상승) |
| ding | 종 화음(C6 E6 G6) | B 완벽 |
| thud | 낮게 떨어지는 사인 + 노이즈 | B 덜 익음 |
| hiss | 노이즈 + 낮은 사각파 | B 탐 |
| clink | 짧은 고음 | C 낟알 하나(칸마다 음높이 상승) |
| boom · crackle | 저음 사인 + 노이즈 / 작은 팝 38개 | C 폭발 |

- 모두 이 스크립트에서 합성한다(녹음·외부 샘플 없음, 라이선스 걱정 없음). 고정 시드라 같은 숫자는 같은 소리.
- 재생은 `app/audio.gd` 한 곳: `SFX` 버스(`default_bus_layout.tres`에 선언 — 실행 중 추가한 버스는 웹에서 무음), 플레이어 10개,
  같은 소리는 45ms 안에 다시 울리지 않는다(폭발의 조각 수백 개가 소리 수백 개가 되지 않게).
- 음소거: 위쪽 스피커 버튼, `?sound=off`로 시작하면 음소거.
- 이 머신에서 들어 볼 수는 없으므로 확인은 두 가지다: 파형을 그림으로 본다(`evidence/step05/waveforms.png`, 위에서부터
  pop_1 coin upgrade sizzle ding thud hiss clink boom crackle), 그리고 브라우저 출력의 실제 신호를 잰다(`specs/sound05.spec.mjs`:
  세 실험 모두 RMS > 0.01, 음소거 중 < 0.001).

## 덜 움직이기

`?motion=reduce`: 팝콘은 한 번에 하나, 반짝임·업그레이드의 뛰어오름·C의 흔들림 없음, 폭발은 조각 6개. 기계는 숨쉬지 않는다.

## 산출물 목록 (원본 → 변환 → 결과 → 출처 → 명령 → 검토 그림)

| 결과 | 원본 | 변환 | 출처·권리 | 명령 | 검토 그림 |
|---|---|---|---|---|---|
| `assets/atlas/sprites.png` (+ `.json`) | `art_src/{piece_a,piece_b,piece_c,kernel,coin,sparkle,smoke}.svg` | Godot SVG 래스터화(scale 1) → 투명 잘라내기 → 선반 포장 256×128 → 가장자리 2px 복제, 밉맵 import | 이 저장소에서 손으로 씀(생성 이미지·외부 그림 없음) | `godot --headless --path popcorn-glory --script res://tools/build_atlas.gd` → `--import` | 아틀라스를 갈색 바탕에 4배로 본 그림(Step 05 작업 중 확인), 게임 안: `evidence/step05/` |

| 기계 12단계 | `art/machine_art.gd` (도형) | 실행 중에 그림, 모양이 바뀔 때만 다시 그림 | 이 저장소의 코드 | — | `evidence/step04/`의 캡처, 업그레이드 버튼 실루엣 |
| 아이콘(뒤로·다시 시작·소리·기록) | `app/ui/icon_button.gd` (도형) | 실행 중에 그림 | 이 저장소의 코드 | — | 위쪽 바 캡처 |

원본(`art_src/`, `build_audio.py`)과 실행용 결과(`assets/`)는 폴더가 다르고, 원본은 팩에 들어가지 않는다(`.gdignore`). 쓰지 않는 자산은 두지 않는다
(`test_assets.gd`가 아틀라스의 모든 그림이 원본과 맞는지, 모든 소리가 실린 것인지 본다).


## 효과 위계 (Step 05 추가 요구)

| 단계 | 언제 | 무엇 | 얼마나 자주 |
|---|---|---|---|
| 1 누름 | 모든 입력 | 기계가 움츠러들고(예비) 감쇠 스프링으로 튕긴다, B는 불꽃·지글, C는 낟알이 칸에 떨어진다 | 매번 |
| 2 팝 | 돈이 들어올 때 | 팝콘이 터져 날고, 동전이 돈 숫자로 날아가 숫자가 부푼다, +N, 팝 소리(높이 ±8%) | 매번(A는 누름마다, B는 판마다, C는 8탭마다) |
| 3 업그레이드 | 버튼을 살 때 | 기계가 뛰어오르고 금빛 팝콘·반짝임, 차임, 새 단계의 모양 | 3분에 5–11번 |
| 4 이정표 | 기계가 **새 외형**에 들어설 때(3·6·9·12단계) | 기계 둘레의 큰 반짝임 고리, 위에서 내리는 금빛 팝콘, 팡파르 — 3을 **대신**한다(겹치지 않음) | 3분에 1–3번 |

- 소리의 우선: 쾅·팡파르가 나는 0.45초 동안 다른 소리를 8dB 낮춘다(더킹). 플레이어 10개, 같은 소리는 45ms 안에 다시 울리지 않는다.
- 음량: 스피커 버튼이 크게(0dB) → 작게(-12dB) → 끔으로 돈다. `?sound=off`로 시작하면 끔.

## 실험별 생산 상태 셋 (같은 카메라·같은 앵커·같은 크기 기준)

기계는 셋이 같은 그림이고(공정한 비교), 상태를 가르는 것은 **생산의 모양**이다. 기계의 외형(클래식 0–2 · 카니발 3–5 · 디럭스 6–8)이 같은 구간에서 함께 바뀐다.

| | 상태 1 (0–2단계) | 상태 2 (3–5단계) | 상태 3 (6단계 이상) | 게임에서의 뜻 |
|---|---|---|---|---|
| A | 누름마다 팝콘 1–3개 | 4–8개, 연타하면 더 높이 · 불꽃 고리 | 11개 이상, 날아오르는 팝콘 줄기 | 한 번의 손짓이 더 많이 터진다 |
| B | 작은 한 판(5–13), 좁은 금색 | 큰 한 판(20–52), 금색이 넓어짐 | 84 이상, 금색 최대 800ms, 금빛 팝콘이 화면을 덮음 | 맞추면 더 크게, 맞추기 쉬워진다 |
| C | **한 번 팡** | **연쇄**: 공중의 팝콘에서 다시 터짐 | **분수**: 위로 곧게 솟는 금빛 줄기 + 연쇄 | 같은 8탭이 다른 모양의 폭발이 된다 |

캡처: `evidence/step04/`의 C 세 단계(Step 04 작업 중 확인한 그림), Step 05 이전·이후 비교는 `evidence/step05/compare/`.
