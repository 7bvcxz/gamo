# AUDIO_AUDIT — 1.0.42 + Grid v2 시점의 소리 전수 조사

상태: `[확정]` · 2026-09-27 · Quality Pass 01 Phase 0

무엇이 어디서 어떻게 울리는지, 그리고 플레이테스트에서 나온 불만이 각각 어느 파일·어느 줄에서
오는지. 측정은 `tools/audio_audit.py`(이 조사와 함께 만든 QA 도구)로 했다. 방향은
`AUDIO_DIRECTION.md`, 바꾼 결과는 `QUALITY_PASS_01_REPORT.md`.

---

## 1. 구조

| 부분 | 파일 | 하는 일 |
|---|---|---|
| 관리자 | `scripts/Audio.gd` | 한 방 소리 18개(`BANK`)를 8개 보이스 풀로, 루프 베드 2개(`wind`·`cold`)를 프레임마다 `apply(화면, 장소, 노출, 밤, delta)`로 |
| 음악 | `scripts/Music.gd` | 파일 없는 시퀀서. `note.wav` 하나를 `pitch_scale`로 올리고 내려 악보(`title`·`home`·`result`)를 친다 |
| 장소 규칙 | `scripts/Zone.gd` | 눈밭/숙소 두 줄. `weather`(바람이 부는가)와 `score`(무엇이 흐르는가) |
| 생성기 | `tools/build_sfx.py` | 모든 WAV를 만드는 파라미터. 표준 라이브러리만. 사인 글라이드 + 잡음 |
| 호출부 | `scripts/Main.gd` | `audio.call("play", ...)` 약 140곳. 전부 **위치 없는** `AudioStreamPlayer` |

- **Audio Bus가 없다.** `default_bus_layout.tres`가 없고 모든 플레이어가 `Master`로 간다. 음악·앰비언스·효과·UI를 따로 줄이거나 숙소에서 바깥만 줄일 방법이 없다.
- **위치가 없다.** 모든 소리가 화면 어디서 일어났든 같은 크기로 들린다. 기지에 벨트가 물건을 넣을 때마다 울리는 `deliver`가 숙소 안(기지에서 600타일)에서도 똑같이 들린다.
- **동시 재생 제한이 없다.** 같은 소리의 35ms 간격 제한 하나뿐이다. 보이스 8개를 돌려쓰므로 많이 울리면 앞 소리가 잘릴 뿐 줄어들지 않는다.
- 사용자 볼륨 설정은 없다(설정 파일에는 `ui_scale`·`game_scale`만). 버스를 새로 만들어도 깨질 호환성이 없다.

## 3. 불만 → 원인

| 플레이테스트에서 들은 것 | 원인 | 근거 |
|---|---|---|
| "브금이라기보다 굉음이 계속 반복된다, 귀가 아프다" | **`wind` 베드.** 26~150Hz 대역 잡음이라 에너지 84%가 150Hz 아래, 62%가 100Hz 아래(중심 88Hz). 눈밭에서는 한 번도 꺼지지 않고, 밤에는 가장 커진다(-19dB). 7.5초 루프 | `build_sfx.py` BEDS.wind `low=26, high=150`; `Audio.apply` 의 `0.45 + night*0.45` |
| 같은 루프가 반복되는 느낌 | 사인 합성 베드의 부분음 간격이 일정해서 **포락선이 주기적**이다. wind는 부분음 0.267Hz 간격 → 3.75초마다 같은 굽이가 온다. 7.5초 루프 안에 두 번 | `bed()` 의 `stride` |
| "얼어붙을 때 반복되는 괴음" | **`cold` 베드.** 260~780Hz 몸통 위에 **분리된 부분음 9개**(2.2~4.6kHz)가 서로 맥놀이하는 6초 루프. 노출 0.45 이상이면(온기 밖에 서기만 해도) -34~-15dB로 올라오고, 추락 직후 체온 40에서는 게임 시작부터 크다. 바람보다 상한이 4dB 높다 | BEDS.cold `layers`; `BED_CEILING cold -15`; `_update_ambience` 의 `maxf(exposure, 0.45)` |
| "오프닝 BGM이 마음에 들지 않는다" | 타이틀 곡이 `note.wav`를 **2옥타브 내려**(`pitch_scale 0.25`, 110Hz) 가장 큰 음(gain 0.9)으로 8박마다 친다. `pitch_scale`은 재생 속도이므로 1초 샘플이 4초 울린다 — 4초마다 오는 낮은 쿵. 오프닝 컷신 31.5초 동안에는 음악이 멎고 **저음 바람만** 남는다 | `Music.SCORES.title` 의 `-24`·`-17`·`-19`; `Audio.apply` 가 "opening" 화면에 `STILL_WIND` |
| "곡괭이가 벽 때리는 소리 같다" | `pick`은 230→88Hz로 **떨어지는** 사인 + 잡음 0.55 + 2배 부분음. 돌이 깨지는 높은 성분이 없고 둔탁한 쿵만 있다. 샘플 1개를 ±6% 피치로만 흔든다 | SOUNDS.pick |
| "고양이 채굴에 작업음이 없다" | 고양이가 광맥·채굴기에서 일할 때 호출하는 소리가 **없다**. 고양이 소리는 `meow`(깨어날 때)와 `nibble`(먹을 때)뿐 | Main.gd 호출부 전수 |
| "공장 소리가 분위기보다 노이즈" | **기지에 물건이 들어올 때마다** `deliver`(884→995Hz 삑)가 -12dB로 울린다. 벨트 한 줄이면 1초에 몇 번이고, 줄이 늘수록 그만큼 늘어난다. 제조기 완료는 `alloy`(-6dB, 두 음 삑) | `_on_item_delivered`, `_on_recipe_produced` |
| "숙소 안에서도 바깥 공장 소리가 들린다" | 위 `deliver`·`alloy`가 **위치 없이** 울린다. 문이 닫혀 바람은 멎지만(Zone.weather) 공장 사건음은 그대로다 | 모든 `audio.call("play")` 가 `AudioStreamPlayer` |
| "전체 방향이 없다" | 버스 없음, 위치 없음, 동시 재생 규칙 없음. 모든 소리가 같은 문법(사인 글라이드)이라 UI 삑과 세계의 소리가 구분되지 않는다 | 1절 |
