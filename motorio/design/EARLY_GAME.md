# EARLY_GAME — 처음 10분과 튜토리얼

이 문서는 초반 UX와 튜토리얼의 단일 원본이다. Early Game 관련 구현·수정은 여기 적힌
원칙을 먼저 적용한다. `CORE_LOOP.md`가 게임이 무엇으로 굴러가는지를 말한다면, 이 문서는
**플레이어가 그것을 어떻게 스스로 알아내는가**를 말한다.

## 1. 원칙 `[확정]`

**튜토리얼의 목표는 모든 행동을 알려주는 것이 아니다. 목표는 알려주되 방법은 플레이어가
발견하게 한다.**

임무를 따라가는 게임이 아니라 **플레이어의 욕망이 다음 행동을 만드는 게임**을 지향한다.
플레이어가 스스로 이렇게 생각하게 만드는 것이 성공의 정의다.

- "저기 뭐가 있지?"
- "저기까지 가고 싶다."
- "열 영역을 더 넓히려면 어떻게 해야 하지?"
- "이 반복 작업을 자동화할 수 없을까?"

최종 목표는 아무 지시 없이 **"열을 더 넓히면 저기까지 갈 수 있겠는데?"** 라고 생각하게
만드는 것이다.

## 2. 도움은 막힌 시간에 비례해 강해진다 `[확정]`

처음부터 화살표나 상세 설명을 보여주지 않는다. 플레이어가 **막혀 있는 시간**에 따라 도움을
점진적으로 올린다.

| 막힌 시간 | 도움 |
|---|---|
| 0~10초 | 아무 도움 없음 |
| 10초 | 관련 오브젝트를 은은하게 강조 |
| 20초 | 간단한 힌트 |
| 40초 | 조금 더 구체적인 힌트 |
| 60초 이상 | 직접적인 안내 · 방향 표시 |

**올바른 행동을 시작하면 관련 도움은 즉시 사라진다.** 숙련자는 거의 아무 도움 없이
지나가고, 초보자는 막혔을 때만 자연스럽게 받는다. 이 사다리의 값은 이 문서가 원본이며
`Defs`의 상수로 옮겨 적는다 — 손으로 두 곳에 적으면 반드시 갈라진다.

## 3. 조작법은 상황에 붙는다 `[확정]`

필요를 느끼기 전에 모든 조작을 설명하지 않는다.

- 시작할 때 캐릭터 옆에 이동 키만 잠깐
- 긴급생존키트에 다가갔을 때만 `[Z] 조사`
- 광맥 앞에서만 `[Z] 채굴`

지금의 `KEY_PROMPTS` 표가 이미 이 모양이다. 남은 일은 **표시 시점을 거리와 막힌 시간에
묶는 것**이지 문구를 늘리는 것이 아니다.

## 4. 임무 문구는 지시가 아니라 Grim의 생각 `[확정]`

명령형 매뉴얼 문구를 피한다. 마지막 연결은 플레이어가 한다.

- 나쁨: `열석 광맥에서 열석 3개를 채굴한 뒤 긴급기지에 공급하세요. (0/3)`
- 좋음: `기지의 열이 오래 버티지는 못할 것 같다.` / `근처의 붉은 돌에서 이상한 열이 느껴진다.`
- 열석을 처음 캔 뒤: `이걸 기지에 넣어볼 수 있을지도...?`

0.20.72에 목표 카드에서 지시 사다리를 걷어냈고 0.20.80에 세 갈래 임무로 나눴다. 남은 일은
**남은 문구를 생각체로 다시 쓰는 것**이다.

## 5. 새 시스템은 이전 단계의 불편에 대한 답으로 등장한다 `[확정]`

기능을 먼저 설명하고 나중에 필요하게 만들지 않는다. **필요 → 발견 → 사용 → 이해** 순서다.

| 플레이어가 느끼는 것 | 그래서 나타나는 것 |
|---|---|
| 춥다 | 열이 필요하다 |
| 저 멀리 가고 싶다 | 온기 영역을 넓힌다 |
| 열석을 계속 직접 캐는 게 귀찮다 | 고양이를 발견한다 |
| 고양이가 나르는 게 느리다 | 컨베이어를 발견한다 |
| 공장을 더 키우고 싶다 | 전기와 구리가 필요해진다 |
| 눈안개 너머가 궁금하다 | 에너지횃불을 만든다 |

## 6. 레벨 디자인 — 활동 영역 **바로 바깥**에 갖고 싶은 것을 둔다 `[확정]`

앞으로 할 일을 계속 지시하는 대신, 지금 닿는 곳 바로 밖에 **확인하고 싶은 것**을 보여준다:
희미한 얼어붙은 고양이, 반짝이는 새 광석, 우주선 파편, 고양이 마을의 실루엣, 이상한 구조물,
눈안개 너머의 빛.

온기를 넓힐 때 숫자만 바꾸지 않는다. **온기가 퍼지고 시야가 열리면서 희미하던 관심 대상이
선명해지는** 피드백을 쓴다.

### 이미 그렇게 되어 있는 것 (2026-08-18 실측, 시드 4242)

- 시작 온기 반경 **7칸**, 안개 미리보기 띠 **2칸** → **9칸까지 희미하게 보인다**
- 가장 가까운 얼어붙은 고양이 **8.6칸** — 반경 밖으로 1.6칸, 즉 **첫 1분부터 보이지만
  닿지 않는 자리**에 이미 누워 있다
- 횃불 비용 **열석 2개 = 손으로 20초**

즉 이 문서가 원하는 "보이는데 못 닿는 것"이 새 콘텐츠 없이 이미 존재한다. 남은 일은 그것을
**욕망으로 바꾸는 것**이다.

## 7. 손을 놓는 속도 `[확정]`

| 시점 | 게임이 하는 일 |
|---|---|
| 첫 1분 | 조작법 + 목표를 알려준다 |
| 약 3분 | 목표를 알려주되 방법은 스스로 |
| 약 5분 | 흥미로운 대상만 보여주고 목표도 플레이어가 만든다 |
| 10분 이후 | 스스로 확장한다 |

## 8. 온기 밖의 것은 땅에 얼어붙어 있다 `[확정]` 2026-08-18

반경 밖의 사물은 **보이지만 가질 수 없다.** 다가가 Z를 누르면 이 문장이 뜬다.

> 땅과 얼어붙었다.  온기로 녹여야 할 것 같다.

**예외는 없다.** 획득하거나 들 수 있는 모든 것이 온기 안에 있을 때만 그렇게 된다 — 캐기,
바닥과 벨트에서 줍기, 상자에서 나온 것, 살아 있는 고양이, 그리고 얼어붙은 고양이까지.
얼어붙은 고양이를 녹이는 방법은 여전히 하나뿐이다: 들어서 기지 근처에 내려놓는다.

이것이 하는 일은 하나다 — **"보인다"를 "갖고 싶다"로 바꾸는 것.** 이 규칙 전까지 온기
반경은 안개와 체온에만 관여했고, 넓힐 이유가 "더 멀리 걸을 수 있다" 하나뿐이었다. 이제
반경은 **세계에 대한 권한**이고, 그 순간 6절의 "바로 바깥에 보이는 것"이 전부 이유가 된다.

### 반드시 함께 지키는 것

- **기지가 서기 전에는 이 규칙이 없다.** 첫 1분에는 제작도 온기도 없으므로, 그때의 거절은
  문 없는 벽이다.
- **거절은 배너로 반복되지 않는다.** 그 물건 위에 조용히 뜨고 잠시 잠긴다. 같은 문장을 세
  번 본 플레이어는 그것을 힌트가 아니라 고장으로 읽는다.
- **잠긴 칸에는 `[Z] 채굴` 같은 안내를 띄우지 않는다.** 되지 않는 일을 하라고 말하는 안내는
  이 저장소가 이미 여덟 버전 동안 겪은 종류의 거짓말이다.

### 이 규칙이 실제로 잠그는 것 (2026-08-18 실측, 시드 4242, 시작 반경 7칸)

| | 반경 밖 |
|---|---|
| 수정조각 | **60 / 60개** |
| 광맥 | 49 / 58개 (안쪽 띠 8~9개는 처음부터 닿는다) |
| 가장 가까운 얼어붙은 고양이 | 8.6칸 — 보이지만 1.6칸 모자란다 |

수정조각이 전부 잠긴다는 것은 `WORLD_AND_STORY`의 "걸어가서 찾는 것"이 **"불이 닿는 데까지
걸어가서 찾는 것"으로 바뀐다**는 뜻이다. 의도된 변경으로 기록한다.

### `[질문]` 반경 밖에 서 있을 수 있는 시간이 너무 짧다

브라우저에서 실제로 걸어 나가 보니, 규칙을 시험하기도 전에 **체온이 먼저 떨어진다.**
반경 밖 냉기는 초당 13이므로 100에서 나가면 약 7.7초 뒤 쓰러진다. 즉 지금 상태에서
"보이는 것을 보러 간다"는 왕복 몇 초짜리 행동이다.

이 규칙은 "저기 있는 걸 못 가진다"고 말하고 추위는 "거기 서 있지도 못한다"고 말한다.
벽이 둘이면 욕망이 아니라 포기가 된다. **에너지횃불이 둘 다에 답이다** — 이미 들고 있는
동안 체온이 줄지 않고, 열을 물건에게 가져간다는 뜻도 그대로다. 횃불을 들었을 때 주위
몇 칸을 `can_touch`로 만들지는 사용자 결정 사항으로 남긴다.

### `[질문]` 고양이가 나르는 것도 잠그는가

이 규칙은 플레이어의 상호작용에 붙였다. 고양이가 반경 밖 바닥의 자원을 주워 오는 것은
지금 그대로다 — 얼어붙은 땅에서 고양이만 집어 올리는 것은 앞뒤가 맞지 않지만, 반대로
잠그면 "탐사해서 떨어뜨려 둔 것을 일손이 회수한다"는 고리가 사라진다. 사용자 결정 전까지는
플레이어에게만 적용한다.
