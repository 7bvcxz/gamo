# Fun Lab 실험 기록

실험마다 무엇을 만들었고 무엇을 쟀는지 적는다. **사람이 해 본 결과와 자동 시험(봇·E2E·헤드리스)으로 잰 숫자를
섞지 않는다.** 자동 시험은 그렇다고 밝혀서 적고, 재미에 대한 판단은 측정에서 바로 나오는 것만 적는다.
사람이 매긴 점수는 `README.md`의 점수표에 적는다.

## Step 86 — 실험실 (2026-11-02, Lab 0.86.0)

만든 것: 실험실 자체(런처, 타일 여섯, 공통 틀, 기록, 스텁). 아직 플레이할 실험은 없다(타일 여섯 모두 SOON → 스텁).

자동 시험으로 확인한 것:
- 런처의 타일 여섯이 폰(390×844), 720×1280, 데스크톱(1280×800)에서 모두 화면 안에 있다(E2E `funlab86`).
- 직접 링크(`#rock`)가 새로고침 뒤에도 같은 실험을 연다. 브라우저 뒤로·앞으로를 따른다.
- 다시 시작하면 레벨 0, 코인 0, 새 기록에서 시작한다. 이전 실행의 기록은 방문 동안 남는다.
- 터치 하나와 클릭 하나가 각각 누름 하나다. 헤드리스 통합 테스트가 처음에 '터치 하나에 누름 둘'을 잡았다.
  Godot 4.7의 누름 모드 버튼은 터치와 그 마우스 사본에 모두 반응한다. 실험실은 터치를 UI 앞에서 멈춘다.
- 숨긴 탭에서 4초가 지나도 플레이 시간은 1.2초 미만으로 늘었다(돌아온 뒤 0.3초 포함). 포커스를 잃은 창은 2초 동안 그대로였다.
  'Paused' 카드를 탭하면 다시 흐른다.
- 기록 창의 JSON·CSV가 실제 다운로드로 받아진다(`funlab-evolution-*.json`).
- 같은 브라우저에서 게임을 먼저 열어 저장한 뒤 실험실을 썼다. 게임의 IndexedDB 항목 30개와 localStorage 사본이 그대로였고,
  실험실이 더한 항목은 0개였다.
