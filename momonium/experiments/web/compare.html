Momonium Fun Lab · 여섯 실험 비교

같은 조건으로 실험마다 3분씩 해 보고, 네 가지를 1–5로 매긴다. 점수는 이 브라우저에만 저장되고 어디에도 보내지 않는다. 내보내기로 파일을 받아 공유한다. 해 보지 않은 실험은 비워 둔다. 빈칸은 0점이 아니다.

실험실 열기시험 방법점수와 순위자동 측정

여섯 실험 — A·C·F를 먼저

3분 시험 방법 (모두 같은 조건)

  1. 매번 새로 시작한 상태로 연다. 아래 버튼은 항상 처음부터 열린다. 시계를 보려면 '기록과 함께'로 연다.
  2. 같은 기기, 세로 방향, 같은 소리 설정(켜거나 끄거나 모두 같게)으로 한다.
  3. 설명을 읽지 않고 시작한다. 실험 이름과 "3분 동안 해 보세요"만 안다.
  4. 시간은 화면이 보이는 동안의 플레이 시간으로 잰다. 실험실의 시계가 그 시간이고, 탭을 숨기면 멈춘다.
  5. 3:00이 되면 실험 안에 작은 카드("Keep playing?" 등)가 뜬다. 솔직하게 답하고, 아래 점수를 매긴다.
  6. 순서를 바꿔 가며 한다(먼저 한 실험이 기준이 되지 않게). 같은 날 여섯을 다 하지 않아도 된다.
  7. 방식이 서로 다르다는 것을 기억한다. C는 탭으로 하고, A·B·F는 지켜보고, D는 수확 순간을 기다리고, E는 생산을 본다. 입력이 많다고 더 재미있는 것은 아니다.

자동 측정 — 객관 수치, 사람의 재미가 아님
