# 오프라인 진행 끔 (Step 79)

주인은 오프라인 자동 생산이 손으로 키우는 증분 게임의 경험을 해친다고 했다. 그래서 **당분간 오프라인 진행을 끈다.**
게임을 닫거나 탭·앱을 배경으로 보내면 시뮬레이션과 모든 생산이 멈춘다. 돌아오면 **멈춘 그 자리에서** 다시 이어진다.
비운 동안에는 아무것도 생기지 않는다. 돈, EXP, 아이템, 일, 연구, 편지, 모모의 자동 작업, 게임 속 날짜 모두 그렇다.

## 1. 놀이 세션: 화면에 보이는 동안만 흐른다

- `src/app/play_session.gd`(`PlaySession`)가 프레임 루프의 시간을 정한다.
  - 화면에 보이면: 프레임의 delta를 쓰되 최대 `balance.session.max_frame_seconds`(0.5초)까지만 쓴다. 멈춤이나 끊김이 섬을 건너뛰게 하지 않는다.
  - 배경이면: 0초. 짓기, 일하는 단계, 모모의 걸음, 익는 작물, 연구, 시계탑, 하루가 모두 **남은 시간**으로 멈춰 있다.
  - 돌아온 첫 프레임도 0초. 브라우저는 숨겨진 동안의 시간을 첫 프레임 하나의 delta로 넘기기 때문이다.
- 배경으로 가는 신호
  - 웹: `visibilitychange`(hidden), `pagehide`(`src/platform/web_lifecycle.gd`). 처음부터 숨겨진 탭으로 열리면 시작부터 배경이다.
  - 앱(안드로이드): `NOTIFICATION_APPLICATION_PAUSED`. 돌아올 때는 `NOTIFICATION_APPLICATION_RESUMED`.
  - 배경으로 갈 때 **한 번 저장**한다(`Main.go_background`). 두 신호가 함께 와도 한 번이다.
- 창이 포커스만 잃고 여전히 보이면(다른 창을 클릭) 저장은 하되 게임은 계속 흐른다. 보이는 플레이이기 때문이다. 수동 저장 버튼과 15초 자동 저장은 그대로다(배경에서는 자동 저장을 쉰다).
- 화면에 보이는 동안의 자동화는 그대로다. 플레이어가 아무것도 누르지 않아도 모모는 스케줄대로 일한다. 서버 틱이나 광고는 없다.

## 2. 불러오기

- `Main._load_or_new()`는 세이브를 **저장된 그대로** 연다. `saved_unix`는 여러 사본(파일·백업·localStorage 미러) 가운데 가장 새것을 고르는 데에만 쓴다(`SaveService.newest`). 지난 시간을 셈하는 데는 쓰지 않는다.
- 세이브 형식, 무결성 검사, 백업, 웹 localStorage 미러, 스키마 이주, Prestige, 모모, 연구, 설정은 바뀌지 않았다. 스키마도 그대로다.
- '다녀오셨어요' 카드는 놀이에서 더 뜨지 않는다. 손상된 세이브나 더 새 버전의 세이브 안내는 예전처럼 같은 카드로 보인다.
- 섬 여정(기록 탭)
  - 옛 세이브에 남은 '자리 비움'과 '따라잡음' 기록은 그대로 읽힌다.
  - 새 기록은 생기지 않는다.
  - 비운 시간이 없는 섬은 '플레이 {p}'만 보여 준다(`journey.totals_played`).

## 3. 남겨 둔 것: 테스트 도구

`OfflineProgress`(따라잡기)는 **일부러 돌리는 도구**를 위해 남겼다. 놀이 경로에서는 부르지 않는다.
- 시뮬레이션 벤치(`tools/bench/sim_bench.gd --offline`)
- 플레이 봇과 캡처 시나리오(`tools/playtest/`, `tools/scenarios/away.gd` 등)
- 브라우저 테스트 다리의 `dev_away` 질의. 다리는 테스트 모드(`window.MOMONIUM_E2E`)에서만 붙는다.

데이터 `balance.offline`의 `_doc`에 같은 내용을 적었다. 다시 켜려면 `Main._load_or_new()`와 `_process()`에서 지운 두 호출을 되살리면 된다(git `momonium/src/app/main.gd`, Step 79 이전).

## 4. 확인

- `tests/unit/app/test_play_session.gd`: 프레임 상한, 배경 0초, 돌아온 첫 프레임 0초, 여러 번 오가도 본 시간만.
- `tests/integration/test_persistence_main.gd`
  - 익는 중인 밭과 40% 캔 모모를 저장하고 2시간·10시간·7일 전 시각으로 쓴다.
  - 연 섬은 시계·돈·EXP·창고·건물·모모·연구·편지·여정이 저장 그대로다. 남은 시간이 같고, 카드는 없고, 그 뒤 프레임대로 흐른다.
  - 배경에서는 한 번 저장하고 멈추며, 돌아온 첫 프레임의 한 시간은 세지 않는다.
- `tests/integration/test_away_report.gd`
  - 열기·다시 열기에 시간을 주지 않는다.
  - 20분 숨겨진 탭이 아무것도 따라잡지 않는다.
  - 카드 그림은 테스트 도구 경로로 검사한다. 여정 줄도 확인한다.
- `tests/integration/ui/test_device.gd`: 앱이 2분 배경에 있다 돌아와도 섬은 그대로이고 비움 기록도 없다.
- E2E `tests/e2e/specs/offline79.spec.mjs`
  - 실제 시간 흐름(시간 배율 1)에서 탭을 **실제 60초** 배경으로 보낸다. 한 번 저장하고, 숨겨진 동안 섬 시계가 1 ms도 움직이지 않는다. 돌아오면 보인 1.5초만 흐른다. 돈·EXP·창고·편지·날짜·일 수는 그대로이고, 그 뒤 놀이로 일을 마친다.
  - 5시간·10시간 뒤 다시 열기, 파일 세이브를 지운 미러 열기: 저장 그대로, 카드 없음, 두 번 지급 없음, 편지 재발송 없음.
  - 보이는 채 포커스만 잃으면 계속 흐른다.
- 배경 탭 재현
  - 이 머신의 헤드리스 Chromium은 페이지를 숨김으로 보고하지 않는다. 다른 탭을 앞으로, 창 최소화, CDP 페이지 동결을 모두 시험했다. 페이지는 계속 초당 60프레임을 그렸다.
  - 그래서 스펙은 브라우저가 배경 탭에 하는 두 가지를 그대로 한다. `visibilityState`가 hidden이 되고 `visibilitychange`가 오며, 다시 보일 때까지 애니메이션 프레임이 오지 않다가 기다리던 프레임이 공백 전체를 들고 온다.
