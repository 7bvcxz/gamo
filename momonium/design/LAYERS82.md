# 화면의 층 (Step 82)

주인이 본 것: 모모를 고른 채 설정을 열면 **스케줄 버튼이 설정 창 위에** 떴다. 상태·연구에서도 같았다(증거 `design/step82/`, 왼쪽 0.81).

원인은 하나였다. UI는 한 CanvasLayer 안에서 **트리 순서대로** 그려지고 눌린다. 그런데 창들은 HUD 바로 앞에 끼워 넣고(`move_child(f, hud.get_index())`), 나머지는 만든 순서대로 뒤에 붙였다. 그래서 다음 것들이 창보다 나중에 그려졌다.
- 스케줄 버튼
- 건설 줄
- 카메라 버튼
- 팁·튜토리얼
- 레벨 업 글자

z_index를 하나씩 키우는 대신, **표 하나**(`src/ui/ui_layers.gd`, `UiLayers`)를 두고 모든 UI가 그 표의 층에 들어가게 했다.

## 1. 층 표

아래가 위로 갈수록 나중에 그려지고, 손가락이 먼저 닿는다.

| 층 | 무엇 | 어디 |
|---|---|---|
| 1. 바다 | `OceanRenderer` | CanvasLayer `UiLayers.BACKGROUND`(−10) |
| 2. 세계 | 섬·건물·모모, 서로는 깊이로 정렬(Step 55/76) | 기본 캔버스 `UiLayers.WORLD`(0) |
| 3. 세계의 표시 | 선택 고리, 스케줄 칸, 파는 바다(`Z_LAND_PREVIEW` 30), 효과(`Z_FX` 40), 경로(`Z_ROUTE` 50) | 세계 안의 z_index. **어떤 UI보다도 아래**(UI는 위의 CanvasLayer) |
| 4. Context | 스케줄 버튼, 건물 카드, 건설 줄, 카메라 버튼, 성능 표시 | UI 뿌리의 첫 층 |
| 4. Announce | 레벨 업 글자(`LevelUpFx`), 배너·색종이(`TierCelebration`) | 둘째 층 |
| 5. Panels | 설정·연구·상태·상점·편지·건물 상세·전력·판매·다녀옴 | 셋째 층 |
| 5. Hud | 모서리·옆 버튼, 위 카드, 고용 메뉴, 버전·데모 표시 | 넷째 층: 창의 어둠막 **위** |
| 5. Guide | 튜토리얼, 팁 | 다섯째 층 |
| 6. Modal | 완전 초기화 확인(`ResetDialog`) | CanvasLayer `UiLayers.MODAL`(90): HUD까지 모든 것 위 |

- UI 뿌리(`UI/Root`)의 자식은 이 다섯 층뿐이다(`UiLayers.TIERS`). 층은 화면 전체 크기의 Control이고, 입력을 받지 않으며(`IGNORE`) 뿌리의 테마를 물려준다. 그래서 옮겨 넣어도 테마·좌표·입력이 그대로다.
- **HUD는 열린 창 옆에서 계속 쓸 수 있다**(그동안의 규칙 그대로). 창 카드는 HUD를 비켜 선다(Step 81). 모서리 버튼을 누르면 그 창으로 바뀐다.
- 새 UI는 층을 고른다. **자기 z_index를 갖지 않는다.**

## 2. 바쁨: 창이나 확인이 열려 있을 때

- `Main.ui_busy()`는 창 하나라도 보이거나 확인 창이 열려 있으면 참이다. 창의 `opened`·`closed`, 확인 창의 `visibility_changed`, 그리고 매 프레임 `_apply_busy`가 그것을 옮긴다.
- **바쁜 동안 Context·Announce·Guide 층을 숨긴다**(`UiLayers.HIDDEN_WHEN_BUSY`). 세계에 관한 것은 창 위에도 옆에도 보이지 않는다.
  - 고른 모모와 스케줄은 그대로다. 버튼만 비켜 있다가, 창을 닫으면 돌아오고 바로 쓸 수 있다.
  - 스케줄을 칠하는 중이었으면 HUD 버튼이 먼저 칠하기를 끝낸다(`end_edit`, 기존 규칙).
- **바쁜 동안 섬은 입력을 받지 않는다**(`InputRouter.blocked`).
  - UI를 지나 섬까지 온 탭·드래그·핀치·휠·호버는 라우터 한 곳에서 버린다. 위젯마다 `mouse_filter`로 막지 않는다.
  - 바빠지는 순간 진행 중인 손가락은 모두 놓는다(`release_all`). 반쯤 그린 스케줄 획은 되돌린다.
- 바쁜 동안 온 **레벨 배너는 기다렸다가** 창을 닫으면 뜬다(`_pending_banner`). 승급·목표 배너는 원래 창을 닫고 뜬다.
- 팁은 숨겨진 동안 시간이 흐르지 않는다. 보이지 않은 채 다 쓰이지 않는다.

## 3. 닫기와 한 번의 탭

- 어둠막(창 밖)과 확인 창의 어둠은 **그 위에서 시작한 누름을 놓을 때만** 닫는다(`PanelViews.dismiss_on_tap`). 터치나 왼쪽·오른쪽 버튼이어야 하고, 휠은 닫지 않는다.
  - 브라우저에서 손가락 하나는 터치와 마우스를 둘 다 만든다. 확인 창의 어둠이 누름만으로 닫히면, 같은 탭의 나머지(놓음)가 그 아래 설정의 어둠막에 닿아 **설정까지 닫혔다**(통합 테스트가 찾았다).
- 휠은 카드(Step 81)와 어둠막·확인 창의 어둠을 지나가지 않는다(`mouse_force_pass_scroll_events = false`). 어둠막 위의 휠이 섬을 확대하던 것을 막았다.
- Esc(폰의 뒤로)는 맨 위의 것 하나만 닫는다. 확인 창이 있으면 확인 창, 다음에 설정.

## 4. 확인

- `tests/integration/ui/test_ui_layers.gd`
  - 층 순서와 각 노드의 층. 창마다 카드가 스케줄 버튼 위, HUD가 창 위. 확인 창 CanvasLayer > UI > 세계(효과 포함) > 바다.
  - 설정·연구·상태·상점·편지마다: 바쁨, 스케줄 버튼과 건물 카드 숨김, 선택 유지. 버튼 자리를 탭해도 스케줄 없음. 닫으면 돌아오고 동작함.
  - 바쁜 동안 라우터는 탭·핀치를 버리고, 닫으면 다시 받는다.
  - 획 도중 창이 열리면 손가락을 놓고 획을 되돌린다.
  - 어둠막 위의 휠은 닫지도 확대하지도 않고, 탭은 닫는다.
  - 확인 창 아래 HUD 버튼 자리 탭은 연구를 열지 않는다. 어둠이 취소하고 설정은 남는다. Esc는 확인 창 → 설정 순.
  - 레벨 배너는 창이 닫힐 때 뜬다. 튜토리얼은 창 동안 숨었다가 돌아온다.
- `tests/integration/ui/test_reset_all_data.gd`: 어둠 탭을 누름과 놓음으로 보낸다.
- E2E `tests/e2e/specs/layers82.spec.mjs`(폰, 폰 720×1280, 데스크톱, 진짜 탭)
  - 모모를 고르고 설정·연구·상태·상점·편지를 HUD로 연다. 매번 버튼이 그려지지 않는지 확인한다.
  - **버튼 자리의 픽셀**이 창의 것으로 바뀌는지 잰다. 0.81은 7~29, 0.82는 63~120이고 기준은 45다.
  - 버튼 자리 탭 → 스케줄 없음. Esc로 닫으면 돌아오고 탭하면 스케줄이 켜진다.
  - 확인 창이 UI보다 높은 층이다. 그 아래 HUD 연구 버튼 탭 → 어둠만 취소하고 설정은 남는다. 스케줄 자리 탭 → 스케줄 없음. Esc 두 번.
  - 열린 창 위의 핀치·드래그(폰), 어둠막과 카드 위의 휠(데스크톱): 카메라·돈 그대로. 닫으면 같은 손짓이 섬을 움직인다.
  - 튜토리얼과 레벨 배너는 연구 창 동안 비켰다가 닫으면 돌아온다.
- 증거 `design/step82/`: 같은 장면의 0.81(왼쪽)과 0.82(오른쪽).
