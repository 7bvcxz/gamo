# Bubble Wrap Empire — Step 04 조작감 패스 (2026-11-25)

시간 상자 한 번. 편집 전에 네 화면(360×800, 390×844, 412×915, 데스크톱 1280×720)에서 직접 보았다(`before/`), 고친 뒤 같은 화면을 다시 찍었다(`after/`).
검사: `node bubble-wrap-empire/tests/e2e/feel.mjs`(24개), `views.mjs`(스크린샷).

## 고친 것
- **가로/데스크톱 레이아웃**: 업그레이드가 행으로, 엄지 칸은 작은 정사각형으로 내려앉고 시트는 둘과 겹치지 않는 범위에서 커진다(데스크톱 시트 275×330 → 309×370 css px). e2e가 처음에 **행과 엄지 칸이 겹치는 내 버그**를 잡았고 고쳤다. UI 배율은 높이 기준 열로 계산해 넓은 창에서 UI가 부풀지 않는다.
- **제스처 취소·고착 방지**(Snowball과 같음): `touchcancel`·포커스 잃음·탭 숨김은 취소(Godot Web은 `touchcancel`을 일반 release로 전달해 취소된 터치가 한 번의 터짐이 되던 문제 해결, Step 02 보고의 알려진 문제), 1.2초 넘게 안 끝난 제스처는 새 터치가 대체, 8초 넘게 눌린 제스처는 스스로 취소.
- **좌우 반전**(오른쪽 위 ⇄), 숫자 숨김 시 떠오르는 +n도 숨김.
- **압축/파도/리필 읽힘**: 터지는 순간 섬광(채운 원)과 링, 리필이 끝난 뽁뽁이는 살짝 부풀며 흰 테두리가 번쩍(어디가 다시 찼는지 보임), **엄지 칸 아래 터치 세기 막대**: 연속 터치 감쇠(Step 03)가 값을 줄이는 동안 막대가 줄었다가 차오른다(감쇠에 시각 단서가 없다는 Step 03의 한계를 줄임).
- **햅틱**(선택, 기능 확인 후)과 하단 여백 +8: Snowball과 같음.

## 확인한 것
- 네 화면 모두: 컨트롤이 화면 안, 서로 겹치지 않음, **시트가 컨트롤을 가리지 않음**, 브라우저 오류 0.
- **오디오는 신호로 쟀다**: 터짐 peak 0.176 / rms 0.076, 컨텍스트 `running`, **음소거하면 peak 0.0000**.
- 반전 후 새 자리의 패드로 터짐. `touchcancel`·blur·탭 숨김(시뮬레이션)·끝나지 않은 제스처·9초 누름 모두 트리거로 세어지지 않거나 스스로 풀림. 80번 빠른 터치(11초) 모두 세어지고 수락된 트리거는 40(0.2초 불응기 상한 57 이내).
- `touch-action: none` 확인(스크롤/새로고침 충돌 없음). 이전 e2e(metrics, input), 헤드리스 17/17, 시나리오 합격선 1.33배 모두 새 빌드에서 통과.

## 숫자 숨김 모드 판정(`numbers_hidden.png`)
터짐의 파도 크기·링·시트가 비는 정도·업그레이드 막대로 행동과 성장이 읽힌다. 절대량은 안 보인다(의도).

## 하지 않은 것 / 한계
- **실제 폰·사람 확인 없음**(햅틱, 소리 크기, 엄지 도달 거리, iOS 안전 영역). 탭 숨김은 시뮬레이션.
- 데스크톱 시트는 아직 작은 편이다(폭이 엄지 칸과 겹치지 않아야 해서 제한됨).
- 반전 시 엄지 칸이 왼쪽 아래가 되지만, 시트 위의 분홍 조준 고리와 지도 대응은 그대로다.
